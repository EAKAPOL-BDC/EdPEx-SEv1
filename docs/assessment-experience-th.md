# NEXORA: หน้าทำแบบประเมินและเมนูดูแบบประเมิน

## การเปลี่ยนแปลง
- F01–F04 แบ่งคำถามเป็นหมวด มีแถบหมวด ความคืบหน้า ปุ่มก่อนหน้า/ถัดไป และบันทึกฉบับร่างแยกจากยืนยันส่ง
- F01–F04 และ F06 เปลี่ยนตัวเลือกจากเมนูเลื่อนเป็นการ์ด radio/checkbox ที่กดได้ทั้งแถว แสดงข้อความตัวเลือกให้เห็นโดยตรง ใช้ตัวอักษรหลัก 16–18 px และพื้นที่กดอย่างน้อย 44 px
- ปรับหน้าจอให้เรียงคอลัมน์เดียวเมื่อพื้นที่แคบ รองรับคีย์บอร์ดและเส้นแสดงตำแหน่งโฟกัส ใช้ fieldset/legend กำกับคำถามแบบหลายตัวเลือก ลดการเคลื่อนไหวเมื่อผู้ใช้ตั้งค่าไว้
- ความคืบหน้าหมายถึงข้อที่เลือกหรือกรอกแล้ว ไม่ใช่คะแนนหรือการยืนยันบันทึก กดบันทึกฉบับร่างเพื่อเก็บคำตอบ
- เมื่อบันทึกฉบับร่าง เก็บหมวดปัจจุบันในลิงก์กลับหน้าตอบ โดยไม่ใส่คำตอบลง URL
- ถ้าไม่มี JavaScript ทุกหมวดและตัวเลือกยังอ่านและส่งผ่านแบบฟอร์มได้ ส่วนตรรกะคำถามตามเงื่อนไขยังประมวลผลเมื่อบันทึกเหมือนเดิม

## ดูแบบประเมินสำหรับผู้ดูแล
เลือก **ดูแบบประเมิน** จากเมนูด้านข้างหรือศูนย์จัดการระบบ เลือก F01–F06 และกลุ่มผู้ประเมิน แล้วเปิดรุ่นที่ต้องการตรวจ ระบบใช้รายการกลุ่มจากรุ่นแบบฟอร์มในพื้นที่นั้น ชุดแค็ตตาล็อกมาตรฐานมี 17 กลุ่ม

- ตรวจเนื้อหาฉบับร่าง เผยแพร่ และยุติใช้งานได้ โดยมีสถานะและรุ่นกำกับ
- แสดงคำถามทุกเงื่อนไขของกลุ่ม พร้อมข้อความอธิบายเงื่อนไข เป็นโหมดตรวจความครบถ้วน ไม่ใช่การจำลองการตอบจริงตามรอบ การเลือกตัวเลือกในหน้า preview ไม่เปลี่ยนการแตกแขนง
- F04 เลือกตำแหน่งผู้ถูกประเมินได้ เช่น คณบดี รองคณบดี และประธานหลักสูตร
- F06 แสดงรายการและช่องเหตุผล/ตัวอย่าง/แผนพัฒนา ส่วนระดับที่คาดหวังและหน้าที่จะเป็นค่าจากการมอบหมายจริง
- F05 เป็นแบบบันทึกกิจกรรม/ตรวจรับ จึงแสดงโครงสร้างข้อมูลสำหรับตรวจสอบ ไม่ใช่แบบสำรวจนิรนาม
- ใช้คำแปลที่รับรองและยังตรงกับข้อความต้นฉบับ ถ้าขาดจะระบุชัดว่าแสดงต้นฉบับภาษาไทย ไม่มีการอนุมัติคำแปลอัตโนมัติ
- ต้องมี catalog.read ในขอบเขตนั้น ไม่อ่านคำตอบรายบุคคล ไม่สร้างรอบ/คำเชิญ/คำตอบ และไม่รับ POST เพื่อบันทึกคำตอบ

## ติดตั้ง
แตกไฟล์ไปที่ Downloads\nexora-assessment-experience หยุดเซิร์ฟเวอร์ด้วย Ctrl+C แล้วรันใน PowerShell เดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-assessment-experience\nexora_web_update.py" --apply-schema
```

จากนั้น Ctrl+F5 และเปิด **ดูแบบประเมิน** รุ่นนี้ไม่มี migration ใหม่ เป็นชุดสะสมที่รวมการแก้ตำแหน่งเมนูและปุ่มยกเลิกรุ่นก่อน

## การตรวจรับ
ทดสอบฐานข้อมูลชั่วคราวและการเรนเดอร์ HTML รวมการเปิดทุกแบบฟอร์ม/กลุ่ม การห้ามบันทึก preview การแยกสิทธิ์ การเก็บค่าศูนย์ และเส้นทางตอบ/บันทึกจริง F03/F06 การเชื่อมเบราว์เซอร์ตรวจภาพถูกปฏิเสธเมื่อเปิด localhost จึงยังไม่ยืนยันภาพบน Chrome/Windows หรือมือถือของผู้ใช้ และยังไม่ได้ประเมินการเข้าถึงตามมาตรฐานโดยผู้ตรวจภายนอก

หลังติดตั้งควรทดลองทั้งหน้าจอกว้าง/มือถือ คีย์บอร์ด การบันทึกฉบับร่าง และคำถามต่อจากคำตอบที่เลือกในรอบทดสอบก่อนใช้เก็บข้อมูลจริง
