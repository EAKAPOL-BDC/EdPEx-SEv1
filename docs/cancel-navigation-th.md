# ปุ่มยกเลิกและกลับหน้าหลัก

เพิ่มปุ่มยกเลิกข้างการบันทึกในหน้าตั้งค่าพื้นที่ เปลี่ยนรหัสผ่าน บันทึก/ตรวจ F05 เตรียมผลแบบสำรวจ และฟอร์มกลางที่เดิมไม่มีปุ่ม (สร้างบัญชี สร้างรอบ เพิ่มช่วงรายงาน)

ฟอร์มที่มีปุ่มยกเลิกอยู่แล้วคงปลายทางเดิม ปุ่มใหม่กลับรายการที่สัมพันธ์กับงาน เช่น สมาชิก รายการ F05 หรือรายการแบบสำรวจ F01–F04 เพิ่มปุ่มกลับรายการแบบประเมินใกล้ปุ่มบันทึกฉบับร่าง F06 และปุ่มกลับหน้าหลักท้ายเนื้อหาหน้าภายในระบบ ยกเว้นหน้าหลักเอง

ทุกปุ่มเป็นลิงก์ภายใน ไม่ส่ง POST ไม่บันทึก ไม่ลบข้อมูล ไม่ใช้ประวัติเบราว์เซอร์เป็นปลายทาง การกรอกที่ยังไม่บันทึกจะไม่ถูกเก็บเมื่อออกจากหน้า จึงควรบันทึกฉบับร่างก่อนหากต้องการทำต่อ

ไม่เปลี่ยนหน้าตอบแบบสำรวจนิรนามให้พาเข้าสู่พื้นที่ผู้ดูแล ชุดนี้รวมการแก้ตำแหน่งเมนูจากรุ่นก่อน ไม่มี migration ใหม่

## ติดตั้ง
แตกไฟล์ไปที่ Downloads\nexora-navigation-buttons หยุดเซิร์ฟเวอร์ด้วย Ctrl+C แล้วรัน:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-navigation-buttons\nexora_web_update.py" --apply-schema
```

รีเฟรช Ctrl+F5 หลังติดตั้ง การตรวจอัตโนมัติไม่ใช่การตรวจภาพในเบราว์เซอร์บนเครื่องผู้ใช้
