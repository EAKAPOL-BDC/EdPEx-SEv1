# Data Visualization ใน NEXORA

เพิ่มเมนู **Data Visualization** สำหรับผู้ที่มีสิทธิ์ดูและตรวจชุดผลในพื้นที่นั้น (`result.review` และ `calculation.validate`) ใช้ฐานข้อมูลและการตรวจสิทธิ์เดิม ไม่มีบริการภายนอกหรือไลบรารีกราฟจาก CDN

อ้างอิงภาพ Dashboard สองแบบที่ผู้ใช้แนบ Endlessloop และ FineReport เป็นชื่อมุมมองที่พัฒนาภายใน NEXORA ไม่ใช่การติดตั้งหรือเชื่อมต่อซอฟต์แวร์ FineReport ของผู้ผลิตภายนอก

## วิธีใช้งาน

1. เปิด **Data Visualization** จากเมนูด้านข้าง
2. เลือก **ผลจริงที่รับรองแล้ว** หรือ **ข้อมูลสาธิต** แล้วกด **แสดงผล** ค่าเริ่มต้นเป็นผลจริง
3. เลือกช่วงรายงาน แบบฟอร์ม F01–F06 กลุ่มผู้ประเมิน หรือค้นหาชื่อ/รหัสตัวชี้วัด
4. เลือกมุมมองที่เหมาะกับงาน ตัวกรองจะตามไปเมื่อเปลี่ยนมุมมอง

| มุมมอง | การใช้งาน |
|---|---|
| ภาพรวม | เลือกมุมมอง พร้อมจำนวนตัวชี้วัด กลุ่ม รายการที่แสดงค่าได้ และกราฟที่เปรียบเทียบกลุ่มได้ |
| Endlessloop | แผงการ์ด F01–F06 บนเส้นเชื่อมโทนม่วง พร้อมวงแหวนครึ่งวงกลมหลายชั้นแสดงความพร้อมของข้อมูล คลิกการ์ดเพื่อกรองแบบฟอร์ม ด้านล่างสำรวจกราฟทีละตัวชี้วัดพร้อมปุ่มก่อนหน้า/ถัดไป เล่นวน 15 วินาที และเต็มจอ |
| FineReport | Dashboard สีน้ำเงินเข้ม แผงวงแหวนความพร้อมรายแบบฟอร์ม กราฟแท่งและมาตรวัดรายกลุ่ม เลือกตัวชี้วัด/มิติ/บริบทได้ สัดส่วนการแสดงค่าและการกระจายรายการผล พร้อมรายละเอียดกราฟคู่ตาราง 8 กราฟต่อหน้าและ CSV ตามตัวกรอง |

จำนวนตัวชี้วัดนับรหัสไม่ซ้ำ จำนวนกราฟแยกมิติและนิยาม จึงอาจมากกว่าจำนวนตัวชี้วัด วงแหวนภาพรวมแสดงสัดส่วนรายการที่เปิดเผยค่าได้จากรายการผลที่ตรงตัวกรอง ไม่ใช่จำนวนผู้ตอบ ความก้าวหน้าของงาน หรือคะแนนผลประเมิน ส่วนมาตรวัดรายกลุ่มใน FineReport แสดงค่าผลประเมินตามสเกลเดียวกับกราฟแท่ง โดยมีหน่วยกำกับ ไม่ใช่การบรรลุเป้าหมาย

## การอ่านกราฟและการเปรียบเทียบ

- ข้อมูลจริงใช้เฉพาะผลรับรองล่าสุดที่ยังไม่ถูกแทนที่ และตรวจ replay ผ่าน `review_summary` ก่อนแสดงผล
- กราฟเปรียบเทียบต้องมีช่วงรายงาน รุ่นแบบฟอร์ม สูตร มิติ หน่วย บริบท และวันที่ตัดข้อมูลตรงกัน แยกแถบตามกลุ่มและรอบ ไม่เฉลี่ยรวมข้ามรอบ
- แสดงส่วนต่างระหว่างกลุ่มเมื่อมีค่าอย่างน้อยสองกลุ่มและมีหนึ่งค่าต่อกลุ่มในกราฟ หากมีหลายรอบของกลุ่มเดียวกัน จะแสดงแถบแยกโดยไม่สรุปว่าเป็นส่วนต่างระหว่างกลุ่ม
- ร้อยละใช้สเกล 0–100 คะแนนใช้ 0–5 หรือ 0–10 ชั่วโมงต่อคนใช้สเกลตามค่าสูงสุดในกราฟนั้น ค่าอยู่นอกสเกลแสดงเป็นตัวเลข ไม่ตัดให้เท่าค่าสูงสุด
- ขีด — หมายถึงซ่อนค่าหรือยังไม่มีผล ไม่ใช่ศูนย์ ศูนย์จริงยังแสดงเป็น 0.00
- ผลที่ถูกซ่อนไม่ถูกนำไปคำนวณส่วนต่างหรือส่งออกค่าใน CSV ข้อมูลสาธิตแยกตารางและกำกับ `SYNTHETIC_DEMO_NOT_ACTUAL` ใน CSV
- ถ้าชุดผลตรวจสอบไม่ผ่าน หน้าเว็บระบุจำนวนชุดที่ไม่นำมาแสดง และการส่งออกหยุดด้วยสถานะ 409 เพื่อไม่ให้ได้ไฟล์ที่ดูเหมือนครบถ้วน
- ถ้าไม่มี JavaScript กราฟทั้งหมดของ Endlessloop ยังแสดงอ่านได้ แต่ไม่มีการเล่นวน/เต็มจอ

## ติดตั้งบนเครื่องผู้ใช้

แตก ZIP ไปที่ `Downloads\nexora-data-visualization-reference` หยุดเซิร์ฟเวอร์เดิมด้วย Ctrl+C แล้วรันใน PowerShell ที่ใช้เปิดระบบเดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-data-visualization-reference\nexora_web_update.py" --apply-schema
```

จากนั้นกด Ctrl+F5 และเปิดเมนู **Data Visualization** รุ่นนี้ไม่มี migration ใหม่ เป็นชุดสะสมรวมหน้าทำแบบประเมิน เมนูดูแบบประเมิน และการแก้ระบบรุ่นก่อน

หากยังไม่มีข้อมูลสาธิต ให้หยุดเซิร์ฟเวอร์และรันตัวช่วยต่อไปนี้เพียงเมื่อจะสร้างข้อมูลสาธิต:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-data-visualization-reference\setup_demo_dashboard.py" --apply
```

ตัวช่วยใช้บัญชี edpexadmin และพื้นที่วิทยาลัยการศึกษาเดิม สร้างข้อมูลสาธิต 63 ตัวชี้วัด 17 กลุ่ม 198 รายการแยกจากผลจริง รันซ้ำไม่เพิ่มข้อมูลซ้ำ ไม่ได้บันทึกข้อมูลเข้าสู่ฐานข้อมูลบนเครื่องคุณจนกว่าจะรันสำเร็จ

## การตรวจสอบรุ่นนี้

ตรวจชุดทดสอบ Data Visualization ที่มีอยู่และกรณีใหม่ของแผงตามภาพอ้างอิง: การนับรายการผล/ค่าศูนย์/ซ่อนค่า การกรองและเลือกตัวชี้วัด นิยามเปรียบเทียบ การรับรองและแทนที่ผล สิทธิ์ข้ามพื้นที่ การอ่านอย่างเดียว และ CSV พร้อมทดสอบปุ่มนำเสนอ JavaScript ผลสรุปอยู่ใน TEST-RESULTS.txt ของชุดติดตั้ง

เบราว์เซอร์ทดสอบถูกบล็อกเมื่อเปิด localhost (ERR_BLOCKED_BY_CLIENT) จึงยังไม่ยืนยันหน้าตาบน Chrome/Windows หรือมือถือ แม้หน้าที่เรนเดอร์และการทำงานฝั่งเซิร์ฟเวอร์ผ่านการทดสอบ ให้ตรวจหลังติดตั้งดังนี้:

1. เปิด Data Visualization เลือกข้อมูลสาธิต กดแสดงผล และเปิด Endlessloop: เห็นการ์ด F01–F06 และวงแหวนครึ่งวงกลมโทนม่วง
2. คลิกการ์ด F03: จำนวนรายการและกราฟต้องตรงตัวกรอง แล้วกดล้างตัวกรองเพื่อกลับทั้งหมด
3. เปิด FineReport: เห็น Dashboard สีน้ำเงินเข้ม เลือก 7.3-38 เพื่อเทียบ ST1/ST2 หน่วยคะแนนเต็ม 10 ตัวเลขบนกราฟแท่งและมาตรวัดต้องตรงกัน
4. เปลี่ยนเป็นผลจริง: เห็นเฉพาะผลที่รับรอง หากยังไม่มีต้องแสดงข้อความไม่มีข้อมูล ค่าที่ซ่อนยังเป็น —
5. ย่อหน้าต่างให้แคบหรือตรวจบนมือถือ: การ์ดและแผงกราฟเรียงใหม่ ปุ่มและตัวเลือกยังใช้งานได้

รุ่นนี้ไม่มี migration ใหม่ ไม่มีการบันทึกหรือเปลี่ยนข้อมูลผลจากการเปิด Dashboard และไม่ได้ติดตั้งหรือเชื่อมต่อผลิตภัณฑ์ FineReport ภายนอก
