# F04: ผู้ถูกประเมินและผู้ตอบสองกลุ่ม

## ความหมาย

ผู้ถูกประเมินคือผู้บริหารในรายการหนึ่งคน-หนึ่งตำแหน่ง-หนึ่งช่วงเวลา รายชื่อ
“ผู้เกี่ยวข้อง” ในหน้ารุ่นเดิมคือผู้มีสิทธิ์ตอบ ไม่ใช่คนที่ถูกประเมินร่วมกัน
ตัวเลือกกลุ่มเดิมกำหนดกลุ่มประจำตัวให้รายชื่อผู้ตอบ จึงไม่ควรทำให้บุคคลหนึ่ง
กลายเป็นทั้ง ST1 และ ST2 ด้วยการเปลี่ยน dropdown เป็นหลายค่า

นโยบายปัจจุบัน: บุคลากรทั้ง ST1 และ ST2 ประเมินผู้บริหารทุกคนทุกตำแหน่ง
โดยเลือกกลุ่มตนเองผ่านหน้าสาธารณะ ไม่ใช้รายชื่อผู้ตอบหรือคำเชิญรายบุคคล
ระบบเก็บรอบและจำนวนอ้างอิงแยกกลุ่มเพื่อไม่ปะปนตัวหารและผล

## สิ่งที่แก้

- หน้าผู้ถูกประเมินแสดงผู้ตอบ ST1 + ST2 ชัดเจน ไม่ให้เพิ่มรายชื่อผู้ตอบ
  ในโหมดสาธารณะ และใช้ปุ่มตรึงแบบสาธารณะเป็นเส้นทางเดียว
- รายชื่อเดิมที่มีอยู่ยังอยู่ในประวัติ ไม่ลบอัตโนมัติ ถ้าเป็นร่างให้ตรวจและ
 นำรายการผู้ตอบออกก่อนตรึงแบบสาธารณะ
- หน้าเพิ่ม/แก้ผู้ถูกประเมินมีคำอธิบายและตัวอย่างนโยบายทั้งสองกลุ่ม
- ปุ่มสร้างรอบจากทะเบียนปีใช้ฟอร์มเลือกทั้งสองกลุ่มและจำนวนอ้างอิงแยก ST1/ST2
  สร้างครบทุกผู้บริหารโดยตรง ไม่ต้องสร้างรอบรายชื่อก่อนเป็นต้นแบบ
- ทางเข้าสร้างรอบสาธารณะจากต้นแบบ F04 เดิมก็ใช้ทั้งสองกลุ่มเช่นกัน
- การสร้างทั้งชุดอยู่ใน transaction; ล้มเหลวแล้วไม่เหลือครึ่งชุด กดซ้ำใช้
  รอบที่มีอยู่โดยไม่เขียนทับการตั้งค่าเดิม หลักฐานแยกต่อการส่งสำเร็จ
- การรับคำตอบตรวจความครบทุกตำแหน่งทั้งสองกลุ่ม การเปิด/เผยแพร่จัดการร่วมกัน
  การพักเผยแพร่และปิดยังทำได้เมื่อมีร่างใหม่หรือรอบยังไม่ครบ
- ป้องกันตัวสร้างรอบแบบรายชื่อเก่าคืนผลสำเร็จศูนย์รอบสำหรับรายการสาธารณะ
- ปรับข้อความยืนยัน ทะเบียนปี ลิงก์จัดการรอบ และคำแนะนำในคู่มือให้สอดคล้อง
