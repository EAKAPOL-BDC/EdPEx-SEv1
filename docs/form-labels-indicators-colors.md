# NEXORA — ชื่อแบบฟอร์ม ตัวชี้วัด และสีประจำกลุ่ม

ต่อยอดชุดทะเบียนกลุ่ม ed9f9f0 โดยเปลี่ยนการแสดงผลดังนี้:

1. F05 แสดงชื่อ “F05 แบบสำรวจข้อมูลการพัฒนาตนเองของบุคลากร”
2. F06 แสดงชื่อ “F06 การประเมินสมรรถนะที่จำเป็น ทักษะ ขีดความสามารถ และค่านิยมของบุคลากร”
3. รายการคำถามแสดงรหัสตัวชี้วัดจาก IndicatorBinding ของรุ่นและพื้นที่เดียวกันใต้ข้อความคำถาม โดยเห็นได้ก่อนกดขยาย หนึ่งข้อแสดงได้หลายรหัส ค้นด้วยรหัสตัวชี้วัดได้ รายการที่ไม่มีการเชื่อมโยงแสดง “ไม่มีตัวชี้วัดเชื่อมโยงโดยตรง”
4. รหัสกลุ่มหลัก กลุ่มย่อย และรหัสเดิมรวม 26 รหัส ใช้สีพื้นคนละสี พร้อมคงรหัสและชื่อกำกับ ใช้ป้ายเดียวกันในทะเบียน คลังแบบฟอร์ม ตัวอย่างแบบฟอร์ม รายชื่อ รอบเก็บข้อมูล คำเชิญ แบบประเมิน และหน้ารายงานที่เกี่ยวข้อง

## การรักษารุ่นข้อมูล

ชื่อใหม่เป็นชื่อที่แสดงในคลังและตัวอย่างแบบฟอร์ม ใช้แทนเฉพาะชื่อมาตรฐานเดิมที่รู้จัก จึงคงชื่อเฉพาะที่ผู้ดูแลตั้งเองไว้ ช่องแก้ชื่อฉบับร่างเสนอชื่อใหม่ให้บันทึกตามกระบวนการเดิม ชื่อเก่าในเนื้อหา/คำแปลที่รับรองแล้วและ snapshot ยังคงตามรุ่นต้นทาง ไม่เขียนทับรุ่นที่ล็อก ไม่เปลี่ยนคำถาม สูตร สิทธิ์ คำตอบ หรือการเชื่อมตัวชี้วัด และไม่มี migration ใหม่

F05 ยังคงขั้นตอนบันทึก/ตรวจข้อมูลกิจกรรมเดิม การเปลี่ยนชื่อไม่ได้เปลี่ยนวิธีคำนวณ F06 ยังคงเป็นการประเมินตนเองและไม่บังคับแนบหลักฐาน

สีอยู่ใน apps/catalog/data/group_colors.json และ stylesheet group-register.css รหัสไม่รู้จักใช้สีกลาง ป้ายยังอ่านได้โดยไม่อาศัยสี ช่องเลือกของระบบปฏิบัติการยังใช้รหัสและชื่อเป็นหลัก

## ผลตรวจครั้งนี้

- 4 tests ผ่าน: ชื่อใหม่/การค้นหา/ไม่แก้ต้นฉบับ, หลายตัวชี้วัดและการค้นหาภายใต้สิทธิ์, ชื่อที่ผู้ดูแลตั้งเอง, การป้องกัน HTML injection ในป้ายกลุ่ม
- ใช้ฐาน SQLite จำลองเฉพาะทดสอบการแสดงผลและ ORM; ไม่ได้ทดสอบ PostgreSQL triggers หรือเชื่อม Supabase
- เทมเพลต 81 ไฟล์ compile ผ่าน; Python compile และ git diff --check ผ่าน
- สีพื้น 26 รหัสไม่ซ้ำ ความต่างสีตัวอักษรขั้นต่ำ 6.11:1
- หน้าตัวอย่างใน preview มาจากเทมเพลตจริงและข้อมูลสมมติ ไม่ส่งข้อมูลจริง
- ยังไม่ได้ติดตั้งบนเครื่อง Windows ของผู้ใช้
