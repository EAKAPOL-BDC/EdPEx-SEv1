# NEXORA: ทะเบียนกลุ่มและรหัส

อ้างอิงทะเบียนตัวย่อ.pdf หน้า 1 — 15 กลุ่มหลัก, 7 กลุ่มย่อย และรหัสเดิมในแบบฟอร์ม 4 รายการ

## ขอบเขตการเปลี่ยนแปลง

- ใช้คำอธิบายกลางในคลังแบบฟอร์ม ช่องเลือกกลุ่ม ตัวอย่างแบบประเมิน รอบเก็บข้อมูล รายชื่อ/คำเชิญ แบบประเมินตนเอง กิจกรรม รายงาน กราฟ และส่วนอ้างอิงกลุ่มบนหน้าคู่มือ
- เพิ่มเมนู “ทะเบียนกลุ่มและรหัส” ภายใต้สิทธิ์ catalog.read พร้อมค้นหารหัส ชื่อ และประเภทกลุ่ม
- คง 17 รหัสกลุ่มผู้ตอบเดิมและเงื่อนไขกลุ่มของแต่ละรุ่นแบบฟอร์ม ไม่เพิ่มสิทธิ์ตอบหรือสร้างประชากรจากทะเบียนอ้างอิง
- ข้อความคำถาม คำแปลที่รับรอง สูตรคะแนน คำตอบ snapshot และผลคำนวณไม่ถูกเขียนทับ; ชื่อใหม่เป็นข้อมูลประกอบการแสดงผล
- ไม่มี migration ใหม่ ไม่ต้อง seed catalog หรือสร้างข้อมูลสาธิตซ้ำ
- คู่มือ PDF ที่ลงรุ่นไว้ยังเป็นเอกสารรุ่นเดิม; ส่วนอ้างอิงกลุ่มบนหน้าเว็บแสดงทะเบียนปัจจุบัน งาน ER Diagram / Data Flow / Workflow ยังคงเลื่อนออกไปตามคำขอ

## ข้อสังเกตที่รักษาความหมายข้อมูล

- S3-1/S3-2 ยังเป็นคนละกลุ่ม; เชื่อมคำอธิบายกับ S3 ศิษย์เก่าตามความหมาย เอกสารแนบไม่ได้กำหนดรหัสย่อยทั้งสองนี้
- ST1/ST2 เป็นกลุ่มบุคลากรเดิม ไม่ใช่รายการในทะเบียนแนบ
- M1/M2 ในทะเบียนคือส่วนตลาด ไม่ใช่มิติสมรรถนะ F06 ไม่มีการจับคู่หรือจัดผู้ตอบเข้าส่วนตลาดโดยอัตโนมัติ
- C4.1 และ C5.1 มีชื่อย่อย “ภาครัฐ” เหมือนกัน แต่คนละกลุ่มหลัก จึงแสดงกลุ่มหลักเสมอ
- S2, SP1 และรหัสอ้างอิงที่ไม่มีในรุ่นแบบฟอร์มจะไม่ปรากฏเป็นกลุ่มที่เลือกเก็บคำตอบได้
- คงชื่อที่กำหนดเองเป็น fallback สำหรับรหัสที่ไม่อยู่ในทะเบียน หากไม่มีคำอธิบายจะแจ้งตรง ๆ ไม่เดาความหมาย
- ชื่อภาษาอังกฤษเป็นคำอธิบาย UI ไม่ใช่การรับรองคำแปลแบบประเมิน
- แก้คำสะกดชื่อคณะ “รัฐศาสร์” ในเอกสารเป็น “รัฐศาสตร์” ในคำอธิบายหน้าจอ

## CSV

คงคอลัมน์เดิมและรหัสเดิม เพิ่มคอลัมน์ด้านท้ายรายงานทั้งสามเส้นทาง (ผลรับรอง, สาธิต, visualization):

- `group_name`: ชื่อกลุ่มหรือชื่อกลุ่มย่อย
- `parent_group_code`: รหัสกลุ่มหลัก ถ้าเป็นกลุ่มย่อย
- `parent_group_name`: ชื่อกลุ่มหลัก
- `group_category`: ประเภทตามทะเบียน
- `group_description`: รายละเอียดฉบับเต็ม

ข้อมูลประกอบ 5 คอลัมน์นี้ใช้ภาษาไทยคงที่ ค่าและการซ่อนผลกลุ่มเล็กใช้เงื่อนไขเดิม
