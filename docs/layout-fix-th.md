# แก้หน้าจอผิดตำแหน่งในรุ่นหลังบ้าน

พบลิงก์จัดการระบบอยู่นอก aside จึงกลายเป็นรายการใน CSS grid หลัก ทำให้เนื้อหาถูกดันไปผิดแถวหรือผิดคอลัมน์ แก้โดยย้ายลิงก์เข้าภายใน sidebar-links และย้ายเปลี่ยนรหัสผ่านจากส่วนหัวเข้ามาในเมนูเพื่อลดความแน่นของแถบด้านบน

ไม่เปลี่ยนข้อมูล สิทธิ์ หรือโครงสร้างฐานข้อมูล ชุดนี้สะสมการพัฒนารุ่นก่อนทั้งหมด

แตกไฟล์ไปที่ Downloads\nexora-layout-fix หยุดเซิร์ฟเวอร์เดิม แล้วรันใน PowerShell ที่ตั้งค่าฐานข้อมูลไว้:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-layout-fix\nexora_web_update.py" --apply-schema
```

รีเฟรช Ctrl+F5 ทดสอบหน้าจัดการระบบ ตั้งค่า ประวัติ และ Dashboard บนเครื่องผู้ใช้ การตรวจอัตโนมัติครอบคลุมโครงสร้าง HTML ของเมนู ไม่ใช่การยืนยันภาพบนเบราว์เซอร์ Windows ของผู้ใช้
