# สรุปผลที่รับรองแล้วและส่งออก CSV

เพิ่มเมนู สรุปผลที่รับรองแล้ว สำหรับ F01–F04 และ F06 ในขอบเขตที่มีสิทธิ์ result.review และ calculation.validate

- ค้นหาชื่อรอบและกรองแบบฟอร์ม แบ่งหน้า 20 ชุดผล
- แสดงเฉพาะชุดผลที่รับรองแล้วล่าสุดของรอบ/แบบฟอร์ม ไม่รวมคำนวณแล้ว รอตรวจ หรือส่งกลับ
- ดูตัวชี้วัด กลุ่ม มิติ หน่วย สถานะ และวันเวลาตัดข้อมูล พร้อมลิงก์ประวัติรับรอง
- ส่งออก CSV UTF-8 ที่เปิดภาษาไทยใน Excel ได้ พร้อมสถานะการซ่อนค่า
- อ่านผลผ่านบริการตรวจผลรวมเดิมทุกครั้ง กลุ่มคำตอบที่ใช้ได้ต่ำกว่า 5 และบริบทที่มีผลหลายรุ่นยังซ่อนค่า ค่าว่างไม่ใช่ศูนย์
- ไม่ส่งออกรายชื่อ รหัสคำเชิญ หรือคำตอบรายบุคคล ไม่มีการรวมค่าข้ามกลุ่มหรือหน่วยนับโดยอัตโนมัติ
- CSV ป้องกันค่าข้อความที่อาจถูกตีความเป็นสูตร
- เมื่อชุดผลตรวจความถูกต้องไม่ผ่าน จะแสดงข้อความและไม่ส่งออก
- เป็นหน้าภายในที่ต้องเข้าสู่ระบบ ยังไม่ใช่การเผยแพร่สาธารณะ

## ติดตั้ง
1. แตกไฟล์ไปยัง Downloads/nexora-approved-results
2. หยุดเว็บเดิม Ctrl+C และรันใน PowerShell เดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-approved-results\nexora_web_update.py" --apply-schema
```

ฟีเจอร์นี้ไม่มี migration ใหม่ ชุดสะสมรวม migration จากรุ่นก่อนเพื่อรองรับเครื่องที่ยังไม่ได้ติดตั้งข้อยกเว้นผู้ดูแล ตัวติดตั้งแสดงรายการที่ค้างก่อนดำเนินการ ไม่เพิ่มสิทธิ์บัญชีให้อัตโนมัติ
3. เปิดเมนู สรุปผลที่รับรองแล้ว
4. ถ้ารอบ F03-ST1-2569 ยังอยู่สถานะรอตรวจ ให้กลับไปตรวจและรับรองก่อน รอบจะปรากฏเมื่อรับรองสำเร็จ
5. เลือก ดูผลรวม แล้วเลือก ส่งออก CSV

รอบทดลองที่มีผู้ตอบ 1 คนจะเห็นตัวชี้วัดพร้อมข้อความซ่อนค่า เป็นพฤติกรรมตามกติกา ไม่ใช่การคำนวณผิด

## ตรวจสอบ
ทดสอบการเลือกเฉพาะผลรับรอง การซ่อนตัวเลขและคำตอบส่วนบุคคลในเว็บ/CSV การปฏิเสธข้ามขอบเขตและผู้ไม่มีสิทธิ์ การกรองแบบฟอร์ม การไม่ส่งออกชุดผลที่ถูกแทนที่ การหยุดเมื่อ validation ไม่ผ่าน และการป้องกัน CSV formula injection
ทดสอบด้วย Django client และฐานจำลอง ยังไม่ได้ทดสอบด้วย browser Windows ของผู้ใช้
