# NEXORA: ศูนย์จัดการระบบ

## งานที่เพิ่ม
- เมนูจัดการระบบ รวมทางเข้าบัญชี/สิทธิ์ ช่วงรายงาน รอบ/ประชากร คลังแบบฟอร์ม และกิจกรรม F05 โดยแสดงเฉพาะเครื่องมือที่มีสิทธิ์
- รายการติดตามรอบร่าง เปิดรับ ตรวจผล และรอบเปิดรับที่พ้นกำหนดปิด ใช้ข้อมูลปัจจุบัน แบ่งหน้า 15 รายการ ไม่ส่งข้อความและไม่ปิดรอบอัตโนมัติ
- รายการสิทธิ์ที่มอบตรงในพื้นที่และจะหมดอายุภายใน 30 วัน แสดง 20 รายการแรก พร้อมลิงก์จัดการสิทธิ์
- ตั้งชื่อพื้นที่ทำงาน บังคับเหตุผล บันทึกประวัติ และป้องกันเขียนทับข้อมูลที่อีกคนเพิ่งแก้ ไม่เปลี่ยนรหัสพื้นที่ เขตเวลา หรือข้อมูลย้อนหลัง
- ค้นประวัติด้วยชื่อการดำเนินการและช่วงวันที่ แบ่งหน้า 25 รายการ เฉพาะเหตุการณ์ที่ระบุ scope_id ตรงกับพื้นที่ ไม่แสดง metadata หรือคำตอบผู้ตอบ
- เปลี่ยนรหัสผ่านตนเองผ่านเมนูด้านบน ต้องยืนยันรหัสผ่านเดิมและผ่านตัวตรวจรหัสผ่านของ Django

## สิทธิ์
ศูนย์จัดการและการตั้งค่าต้องมี role.manage ประวัติต้องมี audit.read การติดตามรอบต้องมี round.manage ทุกหน้าตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ edpexadmin ที่ติดตั้งสิทธิ์ผู้ดูแลจากรุ่นก่อนเข้าถึงได้ตามขอบเขตที่มอบไว้ ไม่ให้สิทธิ์เพิ่มแก่บัญชีอื่นอัตโนมัติ

## ติดตั้ง
แตก ZIP ไปที่ Downloads\nexora-backoffice หยุดเซิร์ฟเวอร์เดิม และเรียกใน PowerShell ที่ตั้งค่าฐานข้อมูลไว้แล้ว:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-backoffice\nexora_web_update.py" --apply-schema
```

รุ่นนี้ไม่มี migration ใหม่ แต่ชุดสะสมรวม migration F05 และข้อมูลสาธิตจากรุ่นก่อน ตัวติดตั้งไม่สร้างข้อมูลสาธิต ไม่เปลี่ยนบัญชี และไม่รับรองผลจริงอัตโนมัติ หลังเปิดระบบให้ Ctrl+F5 แล้วเลือก จัดการระบบ

## งานที่ยังต้องพัฒนาหรือตรวจรับ
การตั้งค่าครั้งนี้ครอบคลุมชื่อพื้นที่และเครื่องมือเดิม ไม่ใช่หน้าปรับทุกค่าเซิร์ฟเวอร์ ไม่มีการแก้รหัสฐานข้อมูลหรือกุญแจลับผ่านเว็บ ยังไม่มีระบบสำรอง/กู้คืนจากหน้าเว็บ อัปโหลดหลักฐาน นำเข้าผลย้อนหลัง เป้าหมาย/คู่เทียบ แจ้งเตือนอัตโนมัติ และเผยแพร่ผลสาธารณะ ตรวจสถานะเพิ่มเติมใน system-readiness-th.md

## ตรวจรับบนเครื่องใช้งาน
1. edpexadmin เข้าจัดการระบบและเปิดเครื่องมือได้ตามสิทธิ์
2. แก้ชื่อพื้นที่ด้วยเหตุผล แล้วค้นเหตุการณ์ workspace.settings_updated
3. ตรวจวันกำหนดปิดและสิทธิ์ใกล้หมดอายุกับข้อมูลจริง
4. ทดลองบัญชีทั่วไปต้องเข้าตั้งค่าหลังบ้านไม่ได้
5. สำรองฐานข้อมูลด้วยเครื่องมือของผู้ให้บริการและทดสอบกู้คืนในฐานทดสอบก่อนใช้งานจริง งานนี้ยังไม่ได้ตรวจบนฐานข้อมูลของผู้ใช้
