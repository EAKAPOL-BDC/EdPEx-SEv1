# NEXORA: ปรับหน้าคลังแบบฟอร์ม

17 กันยายน 2569 · Catalog Interface

## สิ่งที่เปลี่ยน

- ส่วนหัวกระชับ พร้อมไอคอนคลังและชื่อพื้นที่ ลดการแสดงชื่อองค์กรซ้ำเมื่อชื่อเดียวกัน
- ภาพรวมแสดงจำนวนแบบฟอร์ม จำนวนรุ่น และรายการคำถาม/ช่องข้อมูลจากฐานข้อมูล
- กราฟแท่งแบ่งส่วนแสดงสถานะฉบับร่าง เผยแพร่แล้ว และยุติการใช้งาน มีข้อความและจำนวนกำกับ ไม่ใช้สีเพียงอย่างเดียว
- การ์ด F01–F06 ใช้ไอคอนเฉพาะ: ผู้เรียน เครือข่าย บุคลากร ธรรมาภิบาล การพัฒนา และสมรรถนะ
- รหัส รุ่น และไอคอนอยู่แถวเดียวกัน ชื่อแบบฟอร์มแสดงครบ และปุ่มรายละเอียดอยู่ด้านล่างตำแหน่งเดียวกัน
- ตัวกรองใช้ชื่อ/รุ่น รหัสแบบฟอร์ม และสถานะ พร้อมแสดงเงื่อนไขที่เลือกและล้างตัวกรอง
- จัดการ์ด 3/2/1 คอลัมน์ตามความกว้าง รองรับคีย์บอร์ดและลดการเคลื่อนไหวตามค่าของอุปกรณ์
- กรณีไม่พบข้อมูล แสดงข้อความพร้อมทางกลับไปดูทั้งหมด ไม่วาดกราฟที่ดูเหมือนมีข้อมูล

กราฟเป็นสถานะของ **รุ่นแบบฟอร์ม** ตัวเลขทั้งหมดอ้างอิงเฉพาะพื้นที่ที่ผู้ใช้มีสิทธิ์และเงื่อนไขตัวกรอง โดยรวมทุกหน้าผลลัพธ์ จำนวนรายการนับคำถามและช่องข้อมูลในทุกรุ่นที่พบ รวมรายการที่ไม่ได้ใช้งานภายในรุ่นนั้นตามนิยามเดิมของคลัง การ์ดแต่ละใบยังใช้ชื่อภาษาไทยจากต้นฉบับ ส่วนเมนูและคำอธิบายที่เพิ่มรองรับไทย–อังกฤษ

ไม่มีการเปลี่ยนคำถาม คำตอบ สิทธิ์ หรือสถานะเผยแพร่ และไม่มี migration ใหม่

## ติดตั้งชุดอัปเดต

แตก `nexora-catalog-interface.zip` ลง `Downloads\nexora-catalog-interface` หยุดเซิร์ฟเวอร์เดิมด้วย Ctrl+C แล้วรันใน PowerShell เดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-catalog-interface\nexora_web_update.py" --apply-schema
```

เมื่อเห็น `Starting development server` เปิด `http://127.0.0.1:8000/workspace/` เลือก **คลังแบบฟอร์ม** แล้วกด **Ctrl+F5** ชุดนี้รวมโลโก้ มาสคอต ศูนย์คู่มือ และงานรุ่นก่อน

## ตรวจหลังติดตั้ง

1. ตรวจว่ากราฟสถานะรวมกันเท่ากับจำนวนรุ่น และจำนวนบนการ์ดตรงกับหน้ารายละเอียด
2. เลือก F01 หรือเผยแพร่แล้ว แล้วกดค้นหา กราฟและรายการต้องแสดงชุดเดียวกัน
3. ค้นชื่อที่ไม่มีอยู่ ต้องเห็นข้อความไม่พบแบบฟอร์มและกราฟไม่มีข้อมูล
4. ลองย่อหน้าจอ ใช้แป้น Tab ไปยังปุ่ม และเปิดรายละเอียดแบบฟอร์ม

ทดสอบการนับข้อมูลหลายรุ่น การแบ่งหน้า ตัวกรอง ขอบเขตสิทธิ์ และการแสดงผลที่ไม่มีข้อมูลด้วยฐานข้อมูลทดสอบแยก ตรวจ syntax ของ CSS และ template แล้ว การยืนยันภาพจริงบน Chrome/Windows และหน้าจอมือถือยังต้องตรวจหลังติดตั้ง

## สำหรับนักพัฒนา

- `apps/catalog/web.py`: สรุปจาก queryset ที่กรองขอบเขตและเงื่อนไขแล้ว ก่อนแบ่งหน้า โดยแยกการนับรุ่นออกจาก join คำถาม
- `apps/accounts/templates/portal/catalog.html`: โครงสร้างหน้าและกราฟซึ่งมีคำอธิบายเป็นข้อความ
- `apps/accounts/templates/portal/components/catalog_icon.html`: SVG ภายในระบบ ไม่เพิ่ม icon library หรือ CDN
- `apps/accounts/static/portal/catalog-library.css`: สไตล์เฉพาะหน้านี้เพื่อไม่เปลี่ยนเลย์เอาต์ส่วนอื่น
- `tests/test_catalog_summary.py`: ความถูกต้องของจำนวน ขอบเขตข้อมูล การแบ่งหน้า และตัวกรอง
