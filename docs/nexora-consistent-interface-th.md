# NEXORA — รูปแบบหน้ารายการร่วมกัน

รุ่นวันที่ 17 กันยายน 2569 ต่อจากรุ่นปรับคลังแบบฟอร์ม

## ส่วนที่ปรับ

| หน้า | การปรับ |
|---|---|
| จัดเตรียมรอบเก็บข้อมูล | ไอคอน การ์ดรอบ วันเปิด–ปิด ตัวกรอง กราฟสถานะ และแบ่งหน้า |
| แบบสำรวจ F01–F04 | แสดงแบบฟอร์ม กลุ่ม บริบท และสถานะ พร้อมค้นหารอบ |
| งานเก็บข้อมูล F06 | การ์ดแบบเดียวกัน พร้อมวันเปิด–ปิดและกราฟสถานะ |
| กิจกรรมบุคลากร F05 | เพิ่มตัวกรองและแบ่งหน้า 20 รายการ ปุ่มสร้างรอบแสดงเฉพาะผู้มีสิทธิ์ |
| แบบประเมินของฉัน | แสดงกลุ่ม รุ่น กำหนดส่ง และสถานะรอบ พร้อมปุ่มเปิดคำตอบ |
| ดูแบบประเมิน | ไอคอน F01–F06 กลุ่มที่กดได้สะดวก จำนวนรุ่นที่พบ และล้างตัวกรอง |
| ผลรับรองจริง | การ์ดชุดผลกระชับ มีไอคอนแบบฟอร์ม และตัวกรองรูปแบบเดียวกัน |
| จัดการระบบ | ไอคอนตามหน้าที่และปุ่มเปิดเครื่องมือ ตารางติดตามงานใช้คีย์บอร์ดเลื่อนได้ |
| ประวัติการดำเนินงาน | หัวข้อพร้อมไอคอน ตารางใช้คีย์บอร์ดเลื่อนได้ |
| ศูนย์คู่มือ | การ์ดและไอคอนแยกคู่มือผู้ตอบ ผู้ปฏิบัติงาน และนักพัฒนา |
| พื้นที่ทำงาน | ปรับสัดส่วนสถิติและการ์ดพื้นที่ทำงาน |
| สมาชิกและบทบาท | ใช้สัดส่วนหัวข้อร่วมกัน รักษาแบบฟอร์มและประวัติการมอบบทบาท |

คลังแบบฟอร์มและหน้า Admin ใช้การปรับจากรุ่นก่อนซึ่งรวมอยู่ในชุดติดตั้งนี้แล้ว หน้าทำแบบประเมิน แบบฟอร์มบันทึกข้อมูล และกราฟผลรายตัวชี้วัดใช้ระบบรูปแบบร่วมเดิม ไม่ลดขนาดตัวเลือกคำตอบตามความหนาแน่นของการ์ดรายการ

## การใช้งาน

1. เลือกเมนูงานที่ต้องการในแถบด้านข้าง
2. ในหน้ารอบเก็บข้อมูล พิมพ์ชื่อรอบหรือเลือกสถานะ แล้วกด **ค้นหา**
3. กราฟและจำนวนรวมคำนวณจากรายการที่ตรงกับตัวกรองในพื้นที่ที่มีสิทธิ์ โดยรวมทุกหน้า
4. เลือก **เปิดพื้นที่จัดการรอบ** หรือ **จัดการรอบ** บนการ์ด
5. ใช้ **ก่อนหน้า–ถัดไป** เพื่อเปลี่ยนหน้า ตัวกรองเดิมจะยังอยู่
6. กด **ล้างตัวกรอง** เพื่อดูรายการทั้งหมดที่มีสิทธิ์

กราฟแสดงสัดส่วนสถานะรอบ ไม่ใช่ร้อยละการตอบหรือคะแนนประเมิน หน้าเตรียมรอบนับรอบ ส่วน F01–F06 นับรายการแบบฟอร์มและบริบท จึงอาจต่างกันเมื่อรอบเดียวมีหลายแบบฟอร์มหรือบริบท สถานะรอบบนหน้าแบบประเมินของฉันไม่ใช่สถานะการส่งคำตอบรายบุคคล

## หลักการจัดวาง

- การ์ด 3 คอลัมน์บนจอกว้าง ลดเป็น 2 และ 1 คอลัมน์ตามพื้นที่
- ไม่กำหนดความสูงคงที่และไม่ตัดชื่อด้วยจุดไข่ปลา ข้อความยาวตัดบรรทัดได้
- ไอคอนแบบ SVG อยู่ในระบบ ไม่พึ่ง CDN หรือบริการรูปภาพภายนอก
- กราฟมีชื่อสถานะและจำนวนเป็นข้อความ ไม่ใช้สีอย่างเดียว
- ช่องค้นหาและปุ่มหลักสูงอย่างน้อย 44 พิกเซล มี focus สำหรับคีย์บอร์ด และเคารพ reduced motion
- ใช้สีม่วงของ NEXORA ร่วมกับสีประจำแบบฟอร์มตามคลังแบบฟอร์ม

## สำหรับผู้พัฒนา

- `apps/accounts/static/portal/collections.css`: รูปแบบร่วมภายใต้ `.nx-collection` เท่านั้น โหลดท้าย CSS ของ portal
- `portal/components/list_heading.html`, `list_empty.html`, `list_pagination.html`: หัวข้อ สถานะว่าง และเปลี่ยนหน้า
- `portal/components/collection_summary.html`: กราฟสถานะและตัวกรองรอบ
- `apps/rounds/presentation.py`: รับ queryset ที่ตรวจสิทธิ์และกรอง scope แล้วเท่านั้น กรองชื่อ/สถานะก่อนสรุป แบ่งหน้าทีหลัง และเรียงตามวันสร้างกับ primary key
- แต่ละ view ยังคงตรวจสิทธิ์เดิมก่อนเรียกตัวช่วย ไม่สร้างคำตอบหรือแก้ไขรอบจาก GET
- ไม่มี migration ใหม่ ไม่มีการเปลี่ยนสูตรคำนวณหรือเกณฑ์ปกปิดผลกลุ่มเล็ก

## ตรวจรับหลังติดตั้ง

เปิดด้วย Ctrl+F5 แล้วตรวจที่ขนาดหน้าต่างประมาณ 1366, 768 และ 390 พิกเซล: หัวข้อไม่ทับกัน ชื่อยาวอ่านได้ การ์ดเรียงตามพื้นที่ ปุ่มกดได้โดยไม่เลื่อนแนวนอนนอกตาราง ทดลอง Tab, Enter, การค้นหา ล้างตัวกรอง และหน้า 2 ทั้งภาษาไทยและอังกฤษ

การทดสอบโค้ดและการเรนเดอร์ HTML ไม่แทนการตรวจภาพบน Chrome/Windows เครื่องมือเบราว์เซอร์ในสภาพแวดล้อมนี้เปิด localhost ของแอปไม่ได้ จึงยังไม่ได้ยืนยันภาพจากเบราว์เซอร์จริงหรือการติดตั้งบนเครื่องผู้ใช้
