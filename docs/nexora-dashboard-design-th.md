# Dashboard ผลการประเมิน

- หน้ารวมเป็นการ์ดชุดผล พร้อมค้นหาชื่อรอบและกรองแบบฟอร์ม
- หน้ารายละเอียดมีสรุปจำนวนรายการทั้งหมด จำนวนที่แสดงคะแนนได้ และจำนวนที่ซ่อนค่า (ไม่ใช่จำนวนผู้ตอบ)
- ใช้ชื่อตัวชี้วัดจากคลังระบบและชื่อมิติจากแบบฟอร์มรุ่นที่ใช้ พร้อมรหัสอ้างอิง
- คะแนนแสดงแถบตามหน่วยร้อยละ คะแนนเต็ม 5 หรือคะแนนเต็ม 10 ไม่ใช้สีตัดสินผ่าน–ไม่ผ่านหรือรวมคะแนนต่างหน่วย
- ค่าที่ซ่อนไม่แสดงกราฟ และไม่แทนด้วยศูนย์
- ส่วนท้ายหน้าแบบกระชับ ลบข้อความ NEXORA · เชื่อมโยงข้อมูล ขับเคลื่อนองค์กร สู่ความเป็นเลิศ ออกจาก footer
- คงข้อมูลผู้พัฒนา สถาบัน และลิขสิทธิ์
- รองรับขนาดจอด้วย CSS responsive ไม่มีการเพิ่ม migration หรือแก้สูตรคำนวณ

ตรวจสอบด้วย Django tests 20 รายการผ่าน และ render template ด้วยข้อมูลจำลองแล้ว
ยังไม่ได้ตรวจภาพด้วย Chromium เนื่องจากดาวน์โหลด browser ไม่สำเร็จ และยังไม่ได้ทดสอบบน Windows ของผู้ใช้
