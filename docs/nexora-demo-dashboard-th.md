# ข้อมูลสาธิตและ Dashboard เปรียบเทียบ

## ขอบเขตและแหล่งอ้างอิง
เทียบรหัสกับเอกสาร “สรุปตัวชี้วัดที่ต้องการเก็บจากการจัดทำแบบฟอร์ม แบบสอบถาม หรือแบบประเมิน.pdf” ที่ผู้ใช้แนบ: ครบ 63 รหัส รวม 7.4-18A/B/C
ชื่อแสดงผลสาธิตบันทึกใน catalog/demo_indicator_labels.json สกัดจากเอกสารดังกล่าว ไม่แก้ชื่อหรือสูตรในคลังที่เผยแพร่แล้ว
กลุ่ม มิติ สูตร และเวอร์ชันใช้ catalog/indicators.json, groups.json, questions.json และสูตรเวอร์ชัน 1.1 ของระบบ

## ข้อมูลที่บันทึก
- DemoDataset: ชุด DEMO-2569-v1 หนึ่งชุดต่อขอบเขตองค์กร
- DemoSeries: 198 รายการ ครบ 63 ตัวชี้วัด 17 กลุ่ม F01–F06
- แต่ละรายการเก็บข้อมูลต้นทางสมมุติ (คำตอบเฉพาะข้อที่ใช้คำนวณ หรือรายการกิจกรรม F05), ประชากร, สูตร, checksum และผลจากเครื่องคำนวณเดียวกับระบบจริง
- จำลองประชากร 20 หน่วยต่อกลุ่ม คำตอบ 16 หน่วย ไม่มีการนำรายชื่อจริงมาใช้
- คำตอบคำถามเดียวกันของหน่วยและกลุ่มเดียวกันสอดคล้องกันระหว่างตัวชี้วัด
- F05 ใช้ normalized attendance ที่สร้างขึ้นทั้งหมด รวมสถานะตรวจรับและตรวจหลักฐานจำลองเพื่อทดสอบสูตร ไม่มีหลักฐานจริงหรือการรับรองโดยบุคคลจริง
- ไม่มีการสร้างผู้ใช้ รหัสคำเชิญ คำตอบจริง ชุดผลรับรองจริง หรือส่งข้อความให้ใคร
- ไม่เขียนทับรอบ F03-ST1-2569 หรือข้อมูลจริงเดิม
- ชุดสมมุติไม่ปรากฏในรายการผลรับรองจริง และ CSV ทุกแถวระบุ SYNTHETIC_DEMO_NOT_ACTUAL

## การเปรียบเทียบ
แยกตามตัวชี้วัด มิติ แบบฟอร์ม บริบท สูตร เวอร์ชัน และหน่วยที่ตรงกันเท่านั้น บริบททั้งหมดเป็นบริบทสาธิตปี 2569
กราฟแท่งแนวนอนแสดงค่ารายกลุ่มพร้อมชื่อกลุ่ม มีตารางตัวตั้ง ตัวหาร และผล ตัวชี้วัด F05 ความปลอดภัยมีผลแยกสามด้านด้วย
ร้อยละใช้สเกล 0–100 คะแนนใช้ 0–5 หรือ 0–10 ชั่วโมง/คนใช้ค่าสูงสุดของกลุ่มที่แสดง (ไม่ใช่เป้าหมาย)
แสดงช่วงห่างสูงสุด–ต่ำสุดด้วยหน่วยที่เหมาะสม ไม่รวมคะแนนต่างกลุ่ม ไม่อ้างนัยสำคัญทางสถิติ ไม่ใช่ข้อสรุปผลการดำเนินงานจริง
เลือก F01–F06 กลุ่มผู้ประเมิน หรือค้นหารหัส/ชื่อได้ และแบ่งหน้า 12 กราฟ

## การติดตั้งและใช้งาน
หยุดเว็บเดิมด้วย Ctrl+C แล้วรัน setup_demo_dashboard.py --apply จาก PowerShell เดิมที่มีค่าการเชื่อมต่อฐาน development
สคริปต์ติดตั้งโค้ด ตรวจและใช้ migration ที่อยู่ในรายการอนุญาต จากนั้นสร้างข้อมูลผ่านบัญชี edpexadmin ในขอบเขตองค์กรเดิม ก่อนเปิดเว็บ
migration ใหม่ calculations.0007_demo_datasets สร้างตารางข้อมูลสาธิตเท่านั้น ไม่แก้ข้อมูลจริง
บัญชีที่สร้างต้องมี source.manage, calculation.run และ result.review ในขอบเขตที่เลือก
การดูและส่งออกใช้ result.review และ calculation.validate เช่นหน้าสรุปผลเดิม
รันซ้ำจะตรวจข้อมูลและไม่เพิ่มซ้ำ หากข้อมูลสาธิตถูกแก้ไขจนไม่ตรงจะหยุด ไม่เขียนทับเงียบ ๆ

เปิดเมนู สรุปผลที่รับรองแล้ว → ข้อมูลสาธิตและเปรียบเทียบ แล้วกด Ctrl+F5
ลิงก์: http://127.0.0.1:8000/workspace/fc064809-6564-4f74-b303-c32026f82511/insights/demo/

## การทดสอบ
ทดสอบความครอบคลุม 63 ตัวชี้วัด/198 series ทุกกลุ่มและ replay ทุกผลด้วยสูตรจริง การแยกบริบทและเวอร์ชัน การสร้างแบบ transaction/rollback การรันซ้ำและ audit การกรองหน้าเว็บ/CSV สิทธิ์และการแยกข้อมูลจริง
การทดสอบใช้ฐานจำลอง ไม่มีการเชื่อมต่อฐาน Supabase ของผู้ใช้จากสภาพแวดล้อมพัฒนา
ยังไม่ได้ทดสอบภาพในเบราว์เซอร์ Windows ของผู้ใช้
