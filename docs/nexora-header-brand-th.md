# NEXORA — ชื่อระบบในแถบด้านบน

แทนที่ชื่อหน่วยงานข้างโลโก้ด้วยข้อความครบสามบรรทัด:

1. ระบบสารสนเทศขับเคลื่อนองค์กรสู่ความเป็นเลิศ
2. Organizational Excellence Information System
3. เชื่อมโยงข้อมูล ขับเคลื่อนองค์กร สู่ความเป็นเลิศ

ใช้ชื่อทั้งสองภาษาและคำขวัญตามต้นฉบับในทั้งโหมดไทยและอังกฤษ จัดชื่อไทยเป็นหัวเรื่อง ชื่ออังกฤษเป็นข้อความรอง และคำขวัญสีทองเข้ม บนจอกว้างวางข้างโลโก้พร้อมเส้นแบ่งบาง บนจอไม่เกิน 640 พิกเซลจัดข้อความไว้ใต้โลโก้และตัดบรรทัดตามพื้นที่ ไม่ซ่อนข้อความหรือใช้จุดไข่ปลา หน้าเข้าใช้ Admin ใช้การเรียงแนวตั้งเพื่อให้เหมาะกับกรอบขนาดเล็ก

ใช้ส่วนร่วมเดียวกันใน Portal, แบบสำรวจ และ Django Admin รวมหน้าเข้าสู่ระบบ ชื่อหน่วยงานที่เป็นบริบทของข้อมูลและในส่วนท้ายยังคงเดิม ไม่มีการแก้ฐานข้อมูลหรือสิทธิ์

ตรวจผ่านชุดทดสอบโครงหน้าเดิม 2 กรณี ครอบคลุมหน้ารายการ 12 ส่วน หน้าสาธารณะ แบบสำรวจ และ Admin รวมการตรวจสิทธิ์ ตรวจข้อความทั้งสามบรรทัดในโหมดไทย/อังกฤษและไวยากรณ์ CSS แล้ว ยังไม่ได้ยืนยันภาพจริงในเบราว์เซอร์หรือบนเครื่องผู้ใช้
