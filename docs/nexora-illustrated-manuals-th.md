# NEXORA — คู่มือภาพประกอบ รุ่น 1.1

ปรับคู่มือครบ 26 เล่ม: ผู้ตอบ 17 กลุ่ม ผู้ปฏิบัติงาน 8 หน้าที่ และนักพัฒนา 1 เล่ม
ใช้ภาพประกอบ 16 แบบ จัดวางตามงานรวม 84 จุด พร้อมหมายเลข คำอธิบาย และข้อความทดแทนภาพ

## สิ่งที่ผู้ใช้จะเห็น

- เมนู **คู่มือการใช้งาน** แสดงจำนวนภาพในแต่ละเล่ม
- หน้าอ่านมีภาพและคำอธิบายหมายเลขใต้ภาพ กดภาพเพื่อเปิดขนาดเต็มในแท็บใหม่ได้
- ปุ่ม **ดาวน์โหลด PDF** ให้คู่มือรุ่น 1.1 พร้อมภาพเดียวกับหน้าเว็บ สารบัญและเลขหน้า
- กลุ่ม ST1/ST2 มีภาพงาน F06 และ F05 เพิ่มจากวิธีตอบ F01–F04
- คู่มือนักพัฒนามีภาพเส้นทางคำขอและการแยกคำเชิญจากคำตอบ

ภาพทุกภาพเป็น **ภาพจำลองอธิบายขั้นตอน** ที่จัดองค์ประกอบใหม่ให้เหมาะกับการอ่าน ไม่ใช่ภาพจับหน้าจอจากบัญชีจริง
อ้างอิงเมนู/ฟอร์มจากโค้ดรุ่น Interactive Pages 25f1271 บางองค์ประกอบย่อเพื่อให้อ่านชัด
ชื่อกลุ่ม รุ่นแบบ และเมนูจริงขึ้นกับสิทธิ์และการตั้งค่าของหน่วยงาน
ตัวเลขกิจกรรมและกราฟในภาพเป็นตัวอย่าง ไม่ใช่ผลดำเนินงานจริง

## ขอบเขตการแก้ไข

แก้เฉพาะระบบคู่มือและเครื่องมือสร้างเอกสาร ไม่มี migration ไม่มีการสร้างคำตอบหรือแก้ข้อมูลบุคคล
คู่มือผู้ตอบอ่านได้โดยไม่เข้าสู่ระบบ ส่วนเอกสารเจ้าหน้าที่/นักพัฒนายังตรวจการเข้าสู่ระบบก่อนอ่านหรือดาวน์โหลด
ภาพ static เป็นตัวอย่างสาธารณะที่ไม่มีข้อมูลบัญชีจริง ส่วน PDF เจ้าหน้าที่ไม่ถูกย้ายไป static
การอ่านคู่มือไม่เพิ่มสิทธิ์ทำงานหรือเปิดข้อมูลในพื้นที่อื่น

## วิธีสร้างเอกสารสำหรับผู้พัฒนา

1. แก้เนื้อหาใน `scripts/manuals/` และนิยามภาพ/แหล่งอ้างอิงใน `illustrations.py`
2. ติดตั้ง dependencies สำหรับ build ตาม `docs/manuals/requirements-build.txt` รวม Pango ที่ WeasyPrint ต้องใช้
3. รัน `python scripts/build_manual_illustrations.py` เพื่อสร้าง PNG ขนาด 2160 × 1200
4. รัน `python scripts/build_manuals.py` เพื่อสร้าง JSON, PDF และ manifest พร้อม checksum
5. ทดสอบ `python manage.py test tests.test_manuals` ในฐานทดสอบแยก
6. Render PDF เพื่อตรวจหน้าที่มีภาพ สารบัญ ตัวหนังสือไทย และการแบ่งหน้า ก่อนส่งรุ่นใหม่

หน้าเว็บและ PDF ใช้แม่แบบส่วนเนื้อหาร่วมกัน รูปและคำอธิบายจึงไม่แยกเป็นต้นฉบับสองชุด
ผู้ใช้ Windows ไม่ต้องติดตั้งเครื่องมือสร้าง PDF เพื่ออ่านหรือดาวน์โหลดเอกสารที่สร้างไว้แล้ว

## การตรวจรับชุดนี้

- ทดสอบ Django 11 กรณี: ครบ 26 เล่ม/17 กลุ่ม การอ่าน ดาวน์โหลด สิทธิ์ ขอบเขตงาน
  การรับมือ PDF หาย/ถูกแก้/ไม่ตรงต้นฉบับ และความครบของภาพที่ค้นผ่าน staticfiles
- ตรวจ PNG ทั้ง 16 แบบ รวมข้อความไทยและหมายเลขกำกับ
- Render PDF ทุกหน้าเพื่อตรวจขอบหน้าและหน้าว่าง แล้วตรวจภาพตัวอย่างจากเล่มผู้ตอบ เจ้าหน้าที่ และนักพัฒนา
- ตรวจตำแหน่งภาพและคำอธิบายจาก PDF ที่สร้างจริง
- ยังไม่ได้ยืนยันการแสดงผลบนเบราว์เซอร์ Windows ของผู้ใช้

## วิธีเปิดอ่าน

หลังติดตั้ง เข้า **คู่มือการใช้งาน → เลือกกลุ่ม/หน้าที่ → อ่านคู่มือหรือดาวน์โหลด PDF**
หากใช้ ZIP ของชุดนี้ สามารถเปิด `manuals-pdf/index.html` เพื่อเลือกอ่าน PDF ที่รวมไว้ได้ทันที
ไม่จำเป็นต้องเปิดเซิร์ฟเวอร์เพื่ออ่าน PDF แบบออฟไลน์
