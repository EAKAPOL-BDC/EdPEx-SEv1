# หน้าแรกและหน้าเข้าสู่ระบบแบบ Interactive

ปรับเฉพาะสองหน้าตามภาพ โดยใช้แบรนด์และโครงหน้าร่วมเดิม

- หน้าแรก: ลดกรอบตกแต่งและพื้นที่ว่าง ย้ายมาสคอตมาอยู่ในส่วนหลัก เพิ่มปุ่มสำรวจ แบบฟอร์ม / เก็บข้อมูล / ตรวจผล พร้อมคำอธิบายแต่ละขั้น ไม่ใช่ตัวเลขหรือข้อมูลจริงจาก Dashboard
- มาสคอต: ใช้ภาพเดิม ขยับทั้งตัวขึ้นลงและเอียงเบา ๆ มีเงาตอบรับ และกดทักทายได้ เป็นแอนิเมชันภาพสองมิติด้วย CSS ไม่ใช่โมเดลสามมิติที่ขยับแขนขาแยกส่วน
- หน้าเข้าสู่ระบบ: ปรับสัดส่วนข้อความและฟอร์ม เพิ่มแสดง/ซ่อนรหัสผ่านและข้อความแนะนำตามช่องที่โฟกัส การเคลื่อนไหวไม่อ่านค่ารหัสผ่าน ไม่ส่งข้อมูลออกไป และไม่เปลี่ยนการตรวจบัญชี
- มีปุ่มหยุด/เปิดการเคลื่อนไหว เคารพ prefers-reduced-motion และหยุดแอนิเมชันเมื่อแท็บอยู่เบื้องหลัง ไม่มีเสียงหรือการสลับขั้นตอนอัตโนมัติ
- รองรับปุ่มคีย์บอร์ดและชื่อควบคุมตามภาษา เมื่อสลับภาษา ปุ่มซ่อนรหัสผ่านจะกลับสถานะปิดก่อนเก็บค่าฉบับร่างเพื่อป้องกันค่าหาย
- ไม่มี JavaScript ยังอ่านเนื้อหาทุกขั้นตอนและเข้าสู่ระบบด้วยแบบฟอร์มเดิมได้

ตรวจผ่าน Django 4 กรณีและ JavaScript 4 กรณี รวมเส้นทางเข้าใช้ระบบ สิทธิ์ โครงหน้าร่วม การสลับภาษา การควบคุมการเคลื่อนไหว และการแสดง/ซ่อนรหัสผ่าน ตรวจไวยากรณ์ CSS แล้ว ยังไม่ได้ยืนยันภาพจริงในเบราว์เซอร์บนเครื่องผู้ใช้ เบราว์เซอร์คลาวด์ที่เชื่อมต่อยังเป็นคนละตัวกับหน้า LAN ที่ผู้ใช้เปิด

ชุดส่งมอบมี start_release_lan.py สำหรับติดตั้งโค้ดรุ่นนี้และเปิด LAN ด้วยคำสั่งเดียว โดยตรวจ bundle และใช้ worktree แยก ไม่มี migration ใหม่และไม่ปรับ Firewall ใช้ฐาน development ที่ติดตั้งไว้แล้ว /survey/ ผ่าน LAN ยังคงต้องใช้ HTTPS

หลังติดตั้งกด Ctrl+F5 ใน / และ /login/ ทดลองกดขั้นตอน ทักทาย หยุดการเคลื่อนไหว เปิด/ซ่อนรหัสผ่าน และสลับภาษา ทดสอบเพิ่มเติมบนหน้าต่างแคบและเมื่อเปิดการลดการเคลื่อนไหวของอุปกรณ์
