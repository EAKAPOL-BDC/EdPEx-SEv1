# NEXORA: ศูนย์คู่มือการใช้งานและ PDF

รุ่นเอกสาร 1.0 · 17 กันยายน 2569

เพิ่มเมนู **คู่มือการใช้งาน** พร้อมค้นหางาน รหัสกลุ่ม หรือแบบฟอร์ม อ่านบนเว็บด้วยสารบัญ และดาวน์โหลด PDF ที่สร้างไว้แล้ว ไม่ต้องติดตั้งโปรแกรมสร้าง PDF บนเครื่องผู้ใช้

## คู่มือที่จัดทำ

| ประเภท | จำนวน | ครอบคลุม |
|---|---:|---|
| ผู้ตอบแบบประเมิน | 17 เล่ม | C1, C2.1, C2.2, C3.1, C4.1, C5.1, C5.2, C5.3, S1, S3-1, S3-2, CO-1, CO-2, CO-3, CO-4, ST1, ST2 |
| ผู้ปฏิบัติงาน | 8 เล่ม | ผู้ดูแลระบบ, ผู้จัดการแบบฟอร์ม/คำแปล, เจ้าหน้าที่จัดรอบ, เจ้าหน้าที่ F05, ผู้คำนวณ/ส่งตรวจ, ผู้รับรอง, ผู้บริหาร/ผู้อ่านผล, ผู้ตรวจสอบ |
| นักพัฒนา | 1 เล่ม | โครงสร้างเว็บ โมเดลข้อมูล Workflow สิทธิ์ API การทดสอบ การสร้างคู่มือ การติดตั้ง และสำรอง/กู้คืน |

คู่มือแต่ละเล่มระบุผู้ใช้เป้าหมาย ขั้นตอน ผลที่ควรเห็น ข้อควรรู้ และการแก้ปัญหา คู่มือผู้ตอบแยกแบบที่เกี่ยวข้องตามคลังจริง ST1/ST2 อธิบายความต่างของรหัสคำเชิญ F03/F04 กับบัญชี F06 และข้อมูลกิจกรรม F05 มีหัวข้อ English guide เพิ่มสำหรับ C2.2 และ CO-3 เนื้อหาส่วนอื่นเป็นภาษาไทย

ชื่อหน้าที่ในคู่มือไม่ใช่การเพิ่ม Role ใหม่ในฐานข้อมูล หนึ่งบัญชีอาจทำได้หลายหน้าที่ตามสิทธิ์ที่ได้รับจริง

## ใช้งานจากหน้าเว็บ

1. ผู้เข้าสู่ระบบเลือก **คู่มือการใช้งาน** ในเมนูด้านข้าง ผู้ยังไม่เข้าสู่ระบบเลือก **คู่มือ** ที่ส่วนหัว
2. ผู้กำลังตอบแบบสำรวจใช้ลิงก์คู่มือท้ายหน้า ซึ่งเปิดแท็บใหม่เพื่อให้หน้าตอบเดิมยังอยู่ ต้องกดบันทึกฉบับร่างเองก่อนพัก
3. ค้นด้วยรหัส เช่น ST1, C2.2, F06 หรือชื่องาน เช่น คำนวณ แล้วเลือกประเภทคู่มือได้
4. กด **อ่านคู่มือ** ใช้สารบัญไปยังหัวข้อ และกด **ดาวน์โหลด PDF** เพื่อเก็บไฟล์
5. คู่มือเจ้าหน้าที่บางเล่มแสดงลิงก์เปิดหน้างานเฉพาะพื้นที่ที่บัญชีนั้นมีสิทธิ์ เช่น หน้าประวัติสำหรับผู้มี audit.read

คู่มือผู้ตอบ 17 กลุ่มเปิดได้โดยไม่เข้าสู่ระบบ คู่มือผู้ปฏิบัติงานและนักพัฒนาให้บัญชีที่เข้าสู่ระบบอ่านได้ เอกสารเป็นคำแนะนำคงที่ ไม่มีคำตอบหรือข้อมูลจริงขององค์กร การอ่านคู่มือไม่เพิ่มสิทธิ์ทำงานในระบบ

## ติดตั้งชุดสะสมบน Windows

แตก `nexora-manual-center.zip` ลง `Downloads\nexora-manual-center` ให้ไฟล์ตัวเปิดอยู่ในโฟลเดอร์นั้น หยุดเซิร์ฟเวอร์เดิมด้วย Ctrl+C แล้วรันใน PowerShell เดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-manual-center\nexora_web_update.py" --apply-schema
```

หลังเปิดเว็บ กด Ctrl+F5 แล้วเลือก **คู่มือการใช้งาน** หรือเปิด `/manuals/` บน URL ระบบเดิม ชุดนี้รวม Quality Upgrade และงานรุ่นก่อน ไม่มี migration ใหม่และไม่สร้างข้อมูลผู้ตอบหรือสิทธิ์เพิ่มจากการติดตั้ง

หากยังไม่ติดตั้งเว็บ สามารถอ่านทั้ง 26 เล่มจาก `nexora-manuals-pdf.zip` แตกไฟล์แล้วเปิด `index.html` หรือเลือกไฟล์ PDF โดยตรงในโฟลเดอร์ `pdf` ได้

## ตรวจรับหลังติดตั้ง

- เห็นเมนูคู่มือภายในแถบเมนูเดิม ไม่มีการดันเนื้อหาผิดคอลัมน์
- ค้นหากลุ่มของตนและอ่านสารบัญได้ทั้งคอมพิวเตอร์และมือถือ
- ผู้ไม่เข้าสู่ระบบอ่าน/ดาวน์โหลดคู่มือผู้ตอบได้ แต่คู่มือเจ้าหน้าที่พาไปเข้าสู่ระบบ
- บัญชีเจ้าหน้าที่อ่านและดาวน์โหลดคู่มือตามหน้าที่ได้ โดยสิทธิ์ข้อมูลจริงยังคงเดิม
- ลิงก์จากหน้าสำรวจเปิดแท็บใหม่และไม่ส่งแบบฟอร์ม
- PDF แสดงภาษาไทย สารบัญ และเลขหน้าถูกต้องในโปรแกรมอ่าน PDF ของผู้ใช้

ทดสอบด้วย Django client และตรวจ PDF ที่เรนเดอร์แล้ว ยังไม่ได้ติดตั้งหรือยืนยันหน้าจอเว็บบนเครื่อง Windows ของผู้ใช้

## สำหรับผู้บำรุงรักษาคู่มือ

ต้นฉบับอยู่ที่ `scripts/manuals/` ตัวสร้างคือ `scripts/build_manuals.py` ใช้ฟอนต์ Sarabun ที่แนบพร้อม OFL license และ dependencies ใน `docs/manuals/requirements-build.txt` เครื่องมือ build นี้ใช้เฉพาะตอนปรับเอกสาร

เนื้อหาเว็บและ PDF สร้างจากข้อมูลชุดเดียวกัน `docs/manuals/manifest.json` ระบุจำนวนหน้า checksum ของไฟล์ และ checksum ของเนื้อหา หากไฟล์หาย/เปลี่ยนหรือเนื้อหาไม่ตรง PDF ระบบหยุดดาวน์โหลดด้วยข้อความ 503 แทนส่งเอกสารเก่าให้ดูเหมือนเป็นรุ่นล่าสุด หลัง build ใหม่ให้ restart application เพื่อโหลด catalog ที่ cache ไว้ใหม่

การแก้คู่มือควรตรวจขั้นตอนกับบริการและ template ปัจจุบัน ไม่คัดลอกรายงาน increment เก่าที่อาจอธิบายข้อจำกัดซึ่งได้รับการพัฒนาแล้ว
