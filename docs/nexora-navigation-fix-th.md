# แก้การกลับหน้าหลังเพิ่มช่วงรายงาน

ชุดแก้ไขต่อจาก d6a538df92 วันที่ 16 กันยายน 2569 ไม่มี migration เพิ่ม

## สาเหตุ

ตัวเปิดหน้าเพิ่มช่วงรายงานเดิมกลับไปหน้าสร้างรอบ F06 เสมอ แม้เข้ามาจากหน้าแบบสำรวจ F01–F04 ชื่อรอบที่ผู้ใช้พิมพ์เป็นเพียงชื่อ ไม่ได้กำหนดชนิดแบบฟอร์ม ดังนั้นรอบที่ชื่อขึ้นต้น F03 อาจใช้แบบฟอร์ม F06 อยู่

ภาพหน้ากำหนดผู้มีสิทธิ์ตอบที่แสดงทั้ง ST1 และ ST2 สอดคล้องกับหน้าทะเบียน F06 ให้ตรวจแบบฟอร์มจริงในหน้ารายละเอียดก่อนดำเนินการ รอบแบบสำรวจ F03 ที่สร้างผ่านเมนูแบบสำรวจจะมีช่องจำนวนผู้มีสิทธิ์หนึ่งกลุ่ม

## ติดตั้งชุดแก้ไข

1. แตก ZIP ทั้งชุดไปที่ `Downloads\nexora-surveys-navigation-fix`
2. หยุดเว็บด้วย Ctrl+C แล้วใช้ PowerShell หน้าต่างเดิมเรียก:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-surveys-navigation-fix\nexora_web_update.py"
```

ชุดนี้ใช้โครงสร้างฐานข้อมูลจากชุด F01–F04 ที่ติดตั้งแล้ว ไม่ต้องเติม `--apply-schema` ใช้บัญชีและรหัสผ่านเว็บเดิม ตัวเปิดตรวจโค้ดและสร้าง worktree ใหม่ โดยไม่ลบหรือแก้ชนิดรอบที่บันทึกไว้แล้ว

## กลับมาสร้างรอบ F03 ให้ถูกชนิด

1. ในหน้ากำหนดผู้มีสิทธิ์ที่ยังกรอกไม่ครบ กด **ยกเลิก** เพื่อกลับไปดูรายละเอียดรอบ
2. ตรวจหัวข้อ **แบบฟอร์มและเวลา** หากแสดง F06 ให้สร้างรอบใหม่ผ่าน **แบบสำรวจ F01–F04 → สร้างรอบแบบสำรวจ** การเปลี่ยนชื่อรอบเดิมอย่างเดียวไม่เปลี่ยนแบบฟอร์ม
3. ใช้ชื่อใหม่ เช่น `F03-ST1-2569` เพื่อไม่ซ้ำกับรอบเก่า เลือกช่วงรายงานเดิมที่บันทึกไว้แล้ว ไม่จำเป็นต้องสร้างช่วงรายงานซ้ำ
4. เลือกแบบสำรวจ **F03** ที่เผยแพร่แล้ว ผู้ตอบ **ST1** และหน่วยนับ **บุคคล** พร้อมบริบทไทย–อังกฤษและช่วงเวลาจริง หากไม่มี F03 ให้เลือก ให้ตรวจและเผยแพร่ F03 จากคลังแบบฟอร์มก่อน
5. เมื่อบันทึกแล้ว ตรวจหัวข้อ **แบบฟอร์มและเวลา** ต้องเป็น **F03** แล้วเปิด **กำหนด/แก้ไขประชากร**

## กรอกทะเบียนสำหรับ F03 สายวิชาการ

| ช่อง | วิธีกรอก |
| --- | --- |
| ใครบ้างที่มีสิทธิ์ตอบ | บุคลากรสายวิชาการของวิทยาลัยการศึกษา มหาวิทยาลัยพะเยา ตามทะเบียนและเงื่อนไขที่ใช้จริงในรอบนี้ |
| จำนวนหน่วยที่มีสิทธิ์ตอบจริง | จำนวนบุคลากรสายวิชาการที่เข้าเกณฑ์ ณ วันตัดรายชื่อ นับจากทะเบียนจริง |
| ชื่อทะเบียนหรือเอกสารอ้างอิง | ชื่อเอกสารทะเบียนที่ใช้งานจริง |
| ที่เก็บหรือเลขอ้างอิงทะเบียน | ตำแหน่งจัดเก็บหรือเลขเอกสารที่ตามกลับได้ |
| ข้อมูลรายชื่อ ณ วันเวลา | วันและเวลาที่ทะเบียนนี้เป็นปัจจุบัน |
| เหตุผลแก้ไข | สร้างทะเบียนครั้งแรกเว้นว่างได้ เมื่อแก้ทะเบียนเดิมให้ระบุเหตุผล |

กด **บันทึกและดำเนินการ** แล้วเพิ่มรหัสผู้ตอบให้ครบจำนวน ตรวจรายชื่อ ตรึงทะเบียน และเตรียมรอบให้พร้อม ก่อนออกรหัสคำเชิญ

รอบเก่าคงอยู่ให้ตรวจสอบ หากเป็นรอบร่างที่สร้างผิดและยังไม่มีประชากรหรือประวัติงาน ผู้ดูแลสามารถใช้ปุ่มลบรอบร่างในหน้ารายละเอียดได้ตามต้องการ ชุดแก้ไขไม่ลบรอบให้อัตโนมัติ

## สิ่งที่แก้และผลตรวจ

- ลิงก์เพิ่มช่วงรายงานเก็บชนิดหน้าต้นทาง F01–F04 หรือ F06 ไว้ แม้กรอกข้อมูลผิดและต้องแก้ไข
- บันทึกช่วงรายงานแล้วกลับไปหน้าชนิดเดิม พร้อมเลือกช่วงรายงานใหม่
- หากเข้าเพิ่มช่วงรายงานจากหน้ารวม จะกลับไปหน้าจัดเตรียมรอบให้เลือกชนิด
- หน้ากำหนดผู้ตอบและรายการรอบแสดงชนิดและรุ่นแบบฟอร์มที่ผูกอยู่จริง
- ปลายทางเป็นค่าที่ระบบกำหนด ไม่รับ URL ภายนอก และยังตรวจ CSRF/สิทธิ์ตามขอบเขต
- ผ่านการทดสอบ 9 กรณี รวมการกลับหน้า การคงค่าหลัง validation error สิทธิ์และ CSRF การแสดง F06 แม้ตั้งชื่อรอบเป็น F03 งาน F06 จนส่งคำตอบ และการลบรอบร่างที่ยังไม่ใช้งาน
- ทดสอบด้วยข้อมูลสมมติใน PGlite ผ่าน migration ของโครงการ ยังไม่ได้ติดตั้งบนเครื่อง Windows หรือเชื่อมฐาน Supabase ของผู้ใช้
