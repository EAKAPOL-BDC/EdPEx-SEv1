# แผนปรับโครงสร้างฐานข้อมูลสำหรับ F01–F04

ใช้ต่อจากรุ่น a571633f4c ชุดนี้ไม่เปลี่ยนคำแปล ผลตรวจภาษา แบบฟอร์มที่เผยแพร่แล้ว บัญชีผู้ใช้ หรือคำตอบ F06

Migration ที่อนุญาตโดยตัวเปิดมี 4 รายการ โดยใช้เฉพาะรายการที่ยังไม่ติดตั้ง:

1. `surveys.0001_initial` — เพิ่ม SurveyProfile, Invitation, AnonymousSession, AnonymousResponse และ AccessThrottle
2. `surveys.0002_store_guards` — เพิ่มตัวตรวจบริบท/ประชากร/ช่วงเวลา ล็อกคำตอบที่ส่งแล้ว และตรวจการใช้สิทธิ์กับจำนวนคำตอบให้บันทึกพร้อมกัน
3. `calculations.0005_anonymous_source_review` — ขยายฟังก์ชันตรวจแหล่งข้อมูลของชุดผลให้รองรับแบบสำรวจ F01–F04 ควบคู่กับ F06 โดยคงกฎผู้ตรวจอิสระและประวัติรับรอง
4. `catalog.0004_instruction_curation_metadata` — แยกการยืนยันความเหมาะสมของคำชี้แจงออกจากการเปลี่ยนเนื้อหา คงผลตรวจภาษาเดิมเมื่อเนื้อหาไม่เปลี่ยน โดยยังต้องรับรองคำชี้แจงก่อนเผยแพร่ และยังห้ามแก้รุ่นที่เผยแพร่แล้ว

`--apply-schema` เป็นคำสั่งให้ตัวเปิดใช้แผนข้างต้นในฐาน development ที่ตั้งไว้ ตัวเปิดจะไม่ใช้ migration อื่นที่ค้างอยู่ และไม่มีการ seed ข้อมูลหรือเปลี่ยนรหัสผ่าน

ตรวจโค้ดได้ใน bundle และไฟล์ migration ใน worktree การย้อนใช้โค้ด a571633f4c ยังอ่านงานเดิมได้ แต่ไม่มีหน้าแบบสำรวจใหม่ จึงควรหยุดการรับคำตอบแบบสำรวจก่อนย้อนเว็บ ไม่ให้รัน migration ย้อนกลับหลังมีคำตอบ เพราะจะทำให้ข้อมูลแบบสำรวจใหม่ถูกลบ
