# NEXORA — เก็บแบบสำรวจ F01–F04 ผ่านเว็บ

รุ่นนี้ต่อจากชุดเว็บ a571633f4c โดยเพิ่มการรับคำตอบ F01–F04 และใช้ระบบตรวจภาษา เผยแพร่ และตรวจผลที่มีอยู่เดิม F05 งานกิจกรรม/หลักฐานการพัฒนาบุคลากรยังเป็นงานระยะถัดไป

## สิ่งที่ใช้งานได้

- สร้างและแก้ไขรอบร่าง เลือกแบบฟอร์มพร้อมคำแปลที่เผยแพร่แล้ว กำหนดผู้รับผิดชอบ ช่วงรับคำตอบ กลุ่ม หน่วยนับ และบริบทไทย–อังกฤษ
- เพิ่ม แก้ไข ลบหน่วยผู้มีสิทธิ์ในทะเบียนร่าง แล้วตรวจจำนวนและตรึงทะเบียน
- ออก/ออกใหม่/ยกเลิกรหัสคำเชิญรายหน่วย รหัสแสดงครั้งเดียว ไม่ส่งอีเมลหรือข้อความอัตโนมัติ
- ตอบผ่านหน้า `/survey/` ด้วยรหัสคำเชิญ ใช้ได้หนึ่งครั้ง บันทึกร่าง เปลี่ยนภาษา และส่งฉบับสมบูรณ์หรือบางส่วนได้
- คำนวณจากคำตอบที่ส่งแล้วหลังปิดรอบ ตรวจตัวเลขด้วยสูตรเดิม ส่งตรวจและรับรองโดยคนละบัญชีกับผู้จัดทำ

หนึ่งรอบรองรับหนึ่งแบบสำรวจ หนึ่งกลุ่ม หนึ่งบริบท และหนึ่งหน่วยนับ หากมีหลายกลุ่มหรือหลายผู้บริหาร ให้สร้างแยกรอบ ค่าคำนวณจึงไม่ปนบุคคลกับองค์กร

## ติดตั้งครั้งแรก

1. แตก `nexora-surveys-update.zip` ทั้งชุดเป็นโฟลเดอร์ `Downloads\nexora-surveys-update`
2. หยุดเว็บรุ่นเดิมด้วย Ctrl+C ใน PowerShell ที่เปิดเว็บ
3. อ่าน `SCHEMA-UPDATE.md` ในชุด แล้วเรียกตัวเปิดดังนี้:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-surveys-update\nexora_web_update.py" --apply-schema
```

ตัวเปิดตรวจ bundle สร้าง worktree รุ่นใหม่ ตรวจแผน migration และเพิ่มเฉพาะโครงสร้างที่ระบุ หากมี migration อื่นค้างอยู่จะหยุดก่อนดำเนินการ ฐานข้อมูลยังเป็น Supabase development ที่คุณกำหนดไว้เดิม ตัวเปิดใช้ค่าการเชื่อมต่อจากหน้าต่างเดิม หากไม่มีจะถาม โดยซ่อนการพิมพ์รหัสผ่าน

เมื่อติดตั้งแล้ว เปิด `http://127.0.0.1:8000/login/` และใช้บัญชี `edpexadmin` กับรหัสผ่านเว็บเดิม ครั้งต่อไปเรียกคำสั่งเดิมโดยไม่ต้องเติม `--apply-schema`

ใช้ `--install-only` เพื่อเตรียมโค้ดโดยไม่เชื่อมฐานข้อมูล ตัวเปิดไม่เปลี่ยนสาขาหรือไฟล์ในโฟลเดอร์โครงการเดิม

รุ่นนี้รองรับโครงสร้างและสูตรของแบบสำรวจฉบับ 1.1 รวมรุ่นสืบทอดที่แก้ถ้อยคำ การเพิ่ม/ลดคำถามหรือเปลี่ยนตัวเลือกที่ต่างจากโครงสร้างนี้ต้องปรับสัญญาเก็บข้อมูลและสูตรให้รองรับก่อนเปิดรอบ

## เริ่มรอบจากหน้าเว็บ

1. เข้า **คลังแบบฟอร์ม** เลือก F01, F02, F03 หรือ F04 ตรวจคำชี้แจง คำถาม และตัวเลือกไทย–อังกฤษให้ครบ แล้วเผยแพร่รุ่น
2. เข้า **แบบสำรวจ F01–F04 → สร้างรอบแบบสำรวจ** เลือกช่วงรายงานที่รับรองแล้วและรุ่นที่เผยแพร่ กำหนดวันที่จริงของหน่วยงาน
3. ระบุบริบทให้ผู้ตอบเข้าใจ เช่น หลักสูตร/ปีการศึกษา โครงการ/รอบบริการ หรือชื่อผู้บริหาร ตำแหน่งและช่วงดำรงตำแหน่ง ทั้งสองภาษา ตรวจบริบทก่อนยืนยัน
4. เข้า **กำหนดรายชื่อและตรึงประชากร** ระบุจำนวนหน่วยจริงพร้อมที่มาของทะเบียน เพิ่มรายชื่อให้ครบ แล้วตรึงและเตรียมรอบให้พร้อม
5. ในหน้ารอบ ออกรหัสคำเชิญให้แต่ละหน่วย คัดลอกเก็บและส่งผ่านช่องทางที่หน่วยงานเลือกเอง รหัสใหม่ยกเลิกรหัสและฉบับร่างชั่วคราวเดิม ออกใหม่ไม่ได้หลังส่งคำตอบแล้ว
6. กด **เปิดรับคำตอบ** เมื่อถึงเวลาเปิดที่กำหนด ผู้ตอบเข้า `/survey/` และกรอกรหัส ไม่ต้องใช้บัญชีผู้ดูแล
7. เมื่อสิ้นสุดการเก็บ กด **ปิดรับคำตอบ** พร้อมเหตุผล จากนั้น **เตรียมคำนวณ → ตรวจความพร้อม → บันทึกชุดผล → ส่งตรวจ**
8. ผู้ตรวจอีกบัญชีที่ได้รับสิทธิ์ตรวจ/รับรองเปิดชุดผล ตรวจและรับรอง หรือส่งกลับพร้อมเหตุผล

`127.0.0.1` เข้าได้บนเครื่องที่รันเว็บเท่านั้น การให้ผู้ตอบใช้จากอุปกรณ์อื่นต้องมีระบบที่เผยแพร่ด้วย HTTPS ก่อน ชุดนี้ยังไม่ได้เผยแพร่ระบบออนไลน์ให้บุคคลภายนอก

## กฎของคำตอบ

- F01 ใช้กลุ่มตามคำเชิญ C1/C2.1 แบบเต็ม และ C2.2/C3.1 แบบย่อ เลือกชั้นปีหรือช่วงศึกษาที่ตรงกับหลักสูตรตั้งแต่สร้างรอบ
- F02 กำหนดบทบาท บริบท และหน่วยนับจากรอบ คำถามช่วงเวลารองรับเดือน–ปีหรือจำไม่ได้
- F03 G08 เลือกได้ไม่เกิน 3 ข้อ และ “ไม่มี” ต้องเลือกเดี่ยว H01 ยอมรับ 0–10 โดย 0 เป็นค่าจริง
- F04 กำหนดผู้ถูกประเมิน/ตำแหน่งจากรอบ ถ้า P03 ระบุไม่มีข้อมูลพอประเมิน ระบบล้างคำตอบคะแนนและจบเป็น “unable_to_assess”
- คำถาม K “ไม่ทราบ” เป็นคำตอบที่ไม่ถูกตามเฉลย ไม่ใช่ข้อมูลขาดหาย และไม่มีการแสดงเฉลยหรือคะแนนให้ผู้ตอบ
- ข้อเขียนจำกัด 500 ตัวอักษร ข้อความคิดเห็นข้ามได้ คำถามลูกแสดงหลัง **บันทึกและแสดงคำถามต่อ** และล้างคำตอบเมื่อไม่เข้าเงื่อนไข
- บันทึกร่างก่อนสลับภาษา ฉบับร่างมีอายุสูงสุด 24 ชั่วโมงหรือเวลาปิดรอบ แล้วแต่เวลาใดถึงก่อน การเข้ารหัสเดิมจะหมุนรหัส session และเปิดร่างที่ยังไม่หมดอายุ
- หลังส่ง คำตอบแก้ไขไม่ได้และไม่มีการเปิดดูคำตอบผ่านรหัสคำเชิญ เลขรับคำตอบเป็นเพียงหลักฐานการส่ง

## ขอบเขตข้อมูลและสิทธิ์

ทะเบียนคำเชิญเก็บหน่วยผู้มีสิทธิ์และสถานะใช้สิทธิ์ แต่ไม่มีรหัสคำตอบหรือเวลาส่งรายคน ตารางคำตอบเก็บรหัสสุ่ม รอบ กลุ่ม คำตอบและเวลาของคำตอบ โดยไม่มีรหัสบุคคล รหัสคำเชิญ IP หรืออีเมล ฉบับร่างเชื่อมกับ session เฉพาะชั่วคราวและถูกลบเมื่อส่งหรือยกเลิก

การใช้สิทธิ์และการเพิ่มคำตอบทำใน transaction เดียว มีตัวตรวจความสมดุลระดับฐานข้อมูล การส่งซ้ำหรือข้อมูลเปลี่ยนระหว่างเปิดหลายแท็บจะถูกปฏิเสธ คุกกี้ session เป็น HttpOnly, SameSite=Strict และใช้ Secure บน HTTPS ไม่มีการเก็บคำตอบใน localStorage

นี่คือการไม่ระบุชื่อในข้อมูลคำตอบและจำกัดการเชื่อมโยง ไม่ใช่คำรับรองว่าผู้มีสิทธิ์ระดับฐานข้อมูลจะไม่สามารถอนุมานจากเวลา/บริบท/ข้อเขียนได้ ผู้ตอบจึงควรเลี่ยงชื่อและรายละเอียดระบุตัวบุคคลในข้อเขียน

ผู้จัดรอบใช้ `round.manage` และผู้จัดการทะเบียน/คำเชิญใช้เพิ่ม `population.manage` การกำหนดที่มาทะเบียนใช้ `source.manage` ผู้คำนวณใช้ `calculation.run` ผู้ส่งตรวจใช้ `result.submit` + `calculation.validate` ผู้ตรวจใช้ `result.review` + `calculation.validate` และผู้รับรองต้องมี `result.approve` ผู้รับรองต้องเป็นคนละบัญชีกับผู้คำนวณและผู้ส่งตรวจ ไม่มีการเพิ่มสิทธิ์ให้บัญชีใดโดยอัตโนมัติ

ตัวเลขชุดเล็ก n<5 ถูกปิดบังตามระบบตรวจผลเดิม ไม่มีคะแนนสดระหว่างเปิดรอบ ไม่มีหน้าดูคำตอบดิบ/ข้อเขียนให้ผู้บริหาร และชุดผลที่รับรองแล้วยังไม่ใช่การเผยแพร่ต่อสาธารณะ

## งานดูแลก่อนนำไปเปิดใช้ร่วมกัน

ตั้งงานตามเวลาของเซิร์ฟเวอร์ให้เรียก `python manage.py purge_survey_sessions` อย่างน้อยทุกชั่วโมงเพื่อลบร่างที่หมดอายุ แม้ไม่มีคนเปิดเว็บ หน้าเข้ารหัสเรียกการล้างด้วย แต่ไม่ทดแทนงานตามเวลาบนระบบที่ไม่มีผู้เข้าใช้ ต้องกำหนด HTTPS และไม่บันทึก request body/cookie ใน reverse proxy หรือระบบติดตามข้อผิดพลาด หน้า anonymous มีการจำกัดการลองรหัส 20 ครั้งต่อ 10 นาทีต่อแหล่งเชื่อมต่อ ไม่ใช้ X-Forwarded-For ที่ผู้เรียกกำหนดเอง

ยังไม่รวม F05 การตรวจหลักฐานกิจกรรม การส่งคำเชิญอีเมลอัตโนมัติ การเผยแพร่สรุปสู่สาธารณะ หรือรายงานข้อเขียนที่ผ่านการตัดข้อมูลระบุตัวบุคคล
