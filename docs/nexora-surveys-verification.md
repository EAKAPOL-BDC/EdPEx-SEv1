# ผลตรวจชุดอัปเดต NEXORA F01–F04

ตรวจวันที่ 16 กันยายน 2569 ในสภาพแวดล้อมแยก ใช้ข้อมูลสมมติ ไม่มีการเชื่อมต่อหรือแก้ฐาน Supabase ของผู้ใช้

## ผลทดสอบอัตโนมัติ: ผ่าน 109 กรณี

| ชุดทดสอบ | จำนวน | ผล |
| --- | ---: | --- |
| งานจัดการเว็บ รอบเก็บข้อมูล และแบบประเมินตนเอง F06 เดิม | 89 | ผ่าน |
| แบบสำรวจ F01–F04 ตั้งแต่สร้างรอบจนตรวจรับรองชุดผล | 14 | ผ่าน |
| ล็อกบริบทของรอบเมื่อออกคำเชิญแล้ว | 1 | ผ่าน |
| HTTPS/การซ่อนข้อผิดพลาด และขอบเขต migration ของตัวติดตั้ง | 5 | ผ่าน |

ตรวจการสร้างรอบ/รายชื่อ/คำเชิญผ่าน HTTP, CSRF, คุกกี้แยกจากบัญชีผู้ดูแล, บันทึกร่างสองภาษา, รหัสใช้ครั้งเดียว, การออกใหม่และยกเลิก, การส่งซ้ำ, transaction rollback, ช่วงเวลารับคำตอบ, การแก้ไขร่างจากหลายแท็บ, สิทธิ์ข้ามขอบเขต, การล็อกคำตอบที่ส่งแล้ว และ constraint ป้องกันใช้สิทธิ์โดยไม่มีคำตอบ

ตรวจทั้งสี่แบบสำรวจด้วยคำตอบสมมติผ่านการคำนวณจากข้อมูลที่บันทึกจริง การส่งตรวจ และการรับรองด้วยผู้ตรวจอิสระ รวมทั้ง F03 คะแนน 0/การเลือกไม่เกิน 3 ข้อ, F04 ไม่มีข้อมูลพอประเมิน, F02 เดือน–ปี และการล้างคำตอบเมื่อไม่เข้าเงื่อนไข

## สภาพแวดล้อมและขอบเขต

- Python 3.12.14, Django 5.2.17, psycopg 3.2.13 และ PGlite 0.5.8 ผ่าน PostgreSQL socket; ใช้ migration และตัวตรวจระดับฐานข้อมูลของโครงการ
- ผ่าน Django system check, การตรวจ model/migration, การอ่าน template, Python compilation และ `git diff --check`
- ตัวเปิดติดตั้งแบบ `--install-only` ผ่านการตรวจ bundle และสร้าง worktree แยก โดยไม่เชื่อมฐานข้อมูล
- ยังไม่ได้ติดตั้งบน Windows ของผู้ใช้หรือรันบน Supabase จริง ยังไม่ได้ทดสอบความเร็วเมื่อมีผู้ตอบจำนวนมาก/ธุรกรรมพร้อมกันบน PostgreSQL จริง หรือทดสอบภาพหน้าจอในเบราว์เซอร์จริง
- ชุดนี้เตรียมไว้ให้ติดตั้งและตรวจบนเครื่องของผู้ใช้ การให้บุคคลอื่นตอบต้องตั้ง HTTPS และงานลบร่างหมดอายุ ตามคู่มือ

คำตอบที่ส่งแล้วไม่มีคอลัมน์เชื่อมไปยังรายชื่อหรือคำเชิญ แต่ร่างชั่วคราวและข้อมูลเวลา/บริบทยังมีข้อจำกัดด้านการอนุมานตามที่ระบุในคู่มือ ไม่ใช่คำรับรองการไม่ระบุตัวบุคคลอย่างสมบูรณ์
