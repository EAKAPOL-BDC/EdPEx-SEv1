# สิทธิ์ผู้ดูแลระบบครบทุกประเภท

ตามคำสั่งเจ้าของระบบ เพิ่มบทบาท system-administrator-v1 ให้ edpexadmin ใน scope fc064809-6564-4f74-b303-c32026f82511 รวมขอบเขตย่อย ไม่กำหนดวันสิ้นสุด มีสิทธิ์ครบ 21 ประเภทที่ระบบรองรับในรุ่นนี้ ครอบคลุมคลังแบบฟอร์ม คำแปล รอบ ประชากร บัญชี/บทบาท แหล่งข้อมูล คำนวณ ส่งตรวจ ตรวจและรับรองผล และประวัติ

บทบาทเป็นรายการสิทธิ์คงที่ สิทธิ์ใหม่ที่พัฒนาในอนาคตไม่ถูกเพิ่มให้อัตโนมัติ ไม่เปลี่ยนบทบาทเดิม ไม่เพิ่มสิทธิ์ข้ามไปขอบเขตอื่น ไม่มี migration ใหม่
เงื่อนไขการทำงานยังใช้ตามเดิม โดยเฉพาะผู้คำนวณหรือผู้ส่งตรวจไม่สามารถรับรองชุดผลนั้นเอง สิทธิ์ครบไม่ใช่การยกเลิกเงื่อนไขนี้ ไม่รับรองหรือเผยแพร่ผลให้อัตโนมัติ

## ติดตั้ง
1. แตก ZIP ไปยัง Downloads/nexora-system-administrator
2. หยุดเว็บด้วย Ctrl+C แล้วรันใน PowerShell เดิม:

```powershell
& "$env:USERPROFILE\EdPEx-Web\EdPEx-SEv1\.venv\Scripts\python.exe" "$env:USERPROFILE\Downloads\nexora-system-administrator\setup_system_administrator.py" --apply
```

ละ --apply เพื่อดูรายการโดยไม่บันทึก
คำสั่งตรวจบัญชี active Django superuser, สมาชิกองค์กร และ role.manage ที่มีอยู่ใน scope ก่อนบันทึก audit event รันซ้ำไม่สร้าง grant ซ้ำ
เมื่อเว็บเปิดแล้ว รีเฟรช สมาชิกและบทบาท จะพบ system-administrator-v1 ของ edpexadmin
ใช้หน้านี้มอบบทบาทที่มีอยู่ให้บุคลากรอื่นภายในอำนาจที่ตนได้รับได้ การรับรองชุดผลปัจจุบันยังต้องใช้บัญชีผู้ตรวจคนอื่น
เพิกถอนบทบาทนี้ได้ในหน้า สมาชิกและบทบาท ประวัติยังอยู่ และบทบาทเดิมของบัญชียังคงอยู่

## ตรวจสอบ
ทดสอบ 5 รายการสำหรับคำสั่งตั้งค่าผู้ดูแล: preview, idempotency, audit, ขอบเขต, สิทธิ์, และการปฏิเสธบัญชี/role ที่ไม่ตรงเงื่อนไข ทดสอบด้วยฐานจำลอง ไม่เชื่อมฐานผู้ใช้
