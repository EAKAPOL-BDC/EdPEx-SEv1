# NEXORA — จัดการแบบฟอร์มและรอบผ่านเว็บ

ส่วนเพิ่มนี้ใช้หน้าตา NEXORA สีม่วง–ทองและบัญชีเดิม ทำงานผ่านพื้นที่ทำงานปกติ
ใช้โมเดล สิทธิ์ และประวัติการแก้ไขที่มีอยู่แล้ว ไม่มี migration ใหม่
ตัวติดตั้งไม่สร้างข้อมูล ไม่รับรองคำแปล ไม่เผยแพร่แบบฟอร์ม และไม่เพิ่มสิทธิ์ให้อัตโนมัติ

## ขอบเขต

| งาน | ทำผ่านเว็บได้ |
|---|---|
| เนื้อหา F01–F06 | แก้ชื่อ/คำชี้แจง เพิ่ม–แก้ไข–ลบคำถามและตัวเลือกในฉบับร่าง |
| ภาษา | เตรียมคำแปลร่างคำถามเดิม 190 ข้อ พร้อมตัวเลือก ชื่อ และคำชี้แจงที่เสนอ; แก้ภาษาอังกฤษเป็นรายข้อความ |
| ตรวจรับรอง | อ่านไทย–อังกฤษคู่กัน ค้นหา กรองรายการค้างตรวจ รับรองเฉพาะคู่ที่เลือก พร้อมผู้ตรวจ/เวลา |
| เผยแพร่รุ่น | ตรวจความครบถ้วนและเผยแพร่รุ่นกับชุดคำแปลที่ตรวจครบแล้ว |
| จัดเตรียมรอบ F06 | เพิ่มช่วงรายงานตามวันที่จริง สร้าง/แก้รอบ เลือกรุ่นที่เผยแพร่ กำหนดเจ้าของและวันเวลา |
| ผู้มีสิทธิ์ตอบ | กำหนดประชากร/แหล่งอ้างอิง เพิ่ม–แก้ไข–ลบรายชื่อร่าง ตรวจจำนวน ST1/ST2 และตรึงรายชื่อ |
| บัญชีและงาน | สร้างบัญชีผู้ตอบปกติ มอบบทบาทตามสิทธิ์ที่ผู้ดำเนินการมี เชื่อมไปหน้ามอบหมาย/เปิดรับ/คำนวณ/ตรวจผลเดิม |

**การเก็บคำตอบและคำนวณครบวงจรในเว็บรุ่นนี้รองรับ F06**
F01–F05 จัดการเนื้อหา คำแปล และรุ่นแบบฟอร์มได้ แต่หน้ารับคำตอบ/ตรวจรายการเฉพาะแบบยังเป็นงานพัฒนาถัดไป
การเผยแพร่รุ่นแบบฟอร์มทำให้เลือกใช้ในรอบได้ ไม่ใช่การเผยแพร่คำตอบหรือผลรายบุคคลสู่สาธารณะ

## เริ่มจากหน้าปัจจุบันของ edpexadmin

1. เปิด **คลังแบบฟอร์ม → F06 → ดูรายละเอียด**
2. กด **1. ชื่อและคำชี้แจง** ตรวจข้อความให้ตรงกับงานจริง แล้วบันทึก
3. หากต้องแก้คำถาม เปิดรายละเอียดข้อนั้นและกด **แก้ไขคำถาม**
4. กด **2. เตรียมคำแปลไทย–อังกฤษ** ระบบเติมเฉพาะช่องว่างที่มีต้นฉบับตรงกับชุดคำแปลร่าง
5. ใน **3. ตรวจและรับรองไทย–อังกฤษ** อ่านทีละคู่ แก้คำแปลที่จำเป็น แล้วเลือกคู่ที่ตรวจเสร็จ
   ปุ่มเลือกทั้งหมดเลือกเฉพาะหน้าที่กำลังแสดง (10 คู่) จากนั้นกดรับรองรายการที่เลือก
6. กด **4. เผยแพร่** เมื่อข้อความไทยและอังกฤษครบทุกจุดและคำชี้แจงผ่านการตรวจแล้ว
   รุ่นที่เผยแพร่ล็อกเนื้อหา หากต้องแก้ภายหลังให้กด **สร้างรุ่นใหม่** และตรวจรับรองใหม่
7. เปิด **จัดเตรียมรอบ → เพิ่มช่วงรายงาน** ใส่ปีรายงาน พ.ศ. พร้อมวันแรก/วันสุดท้ายจริงของหน่วยงาน
8. กด **สร้างรอบ F06** เลือกรุ่นที่เผยแพร่ กำหนดเจ้าของ วันเปิด กำหนดส่ง วันปิด และคำชี้แจงการใช้ข้อมูล
9. ในรายละเอียดรอบ กด **กำหนด/แก้ไขประชากร** ใส่จำนวน ST1/ST2 และแหล่งอ้างอิงตามจริง
10. กด **เพิ่มผู้ตอบ** ระบุรหัสบุคลากรและกลุ่มให้ครบ ตรวจรายการแล้วกด **ตรึงประชากร**
11. กด **เตรียมพร้อมเปิดรอบ** จากนั้น **มอบหมายผู้ตอบ** กำหนดบัญชีผู้ตอบ หน้าที่ และระดับคาดหวังตามจริง
12. หากผู้ตอบยังไม่มีบัญชี ใช้ **สมาชิกและบทบาท → สร้างบัญชีผู้ตอบใหม่** เลือกบทบาทผู้ตอบที่เหมาะสม
    ผู้ใช้ต้องได้รับรหัสผ่านเริ่มต้นจากผู้ดูแลโดยตรง ระบบไม่ได้ส่งอีเมลให้อัตโนมัติ
13. เปิด **พื้นที่เก็บข้อมูลและผล** แล้วเปิดรับคำตอบ ผู้ตอบใช้ **แบบประเมินของฉัน**
    เมื่อปิดรับจึงคำนวณและส่งชุดผลให้ผู้มีสิทธิ์ตรวจรับรองตามขั้นตอนเดิม

F06 เป็นการรายงานตนเอง ไม่เพิ่มผู้ให้คะแนนแทนผู้ตอบ ไม่บังคับหลักฐาน และไม่กำหนดประชากรจากจำนวนคำถาม
จำนวนบุคลากรและระดับคาดหวังต้องมาจากข้อมูลจริงของรอบ

## คำแปลและประวัติรุ่น

- คำแปลที่เตรียมให้เป็น **ร่างสำหรับผู้รับผิดชอบตรวจความหมาย** ไม่มีการรับรองอัตโนมัติ
- ครอบคลุมคำถามต้นฉบับเดิมทั้ง 190 ข้อ รวม F06 จำนวน 44 ข้อ
- คำถามใหม่หรือข้อความไทยที่แก้จนไม่ตรงชุดร่าง ให้กรอกภาษาอังกฤษในหน้าแก้คำแปลได้
  รุ่นนี้ไม่ได้เรียกบริการแปลอัตโนมัติภายนอก และไม่ต้องมี API key
- ปุ่มเตรียมคำแปลไม่เขียนทับภาษาอังกฤษที่กรอกไว้
- เมื่อแก้ภาษาไทย ข้อที่เปลี่ยนต้องแก้/ยืนยันภาษาอังกฤษให้ตรงต้นฉบับใหม่ ส่วนข้อความที่ไม่เปลี่ยนสามารถเตรียมกลับเข้าสู่สถานะรอตรวจได้
- การรับรองผูกกับข้อความที่ผู้ตรวจเห็น หากมีคนแก้ไขระหว่างเปิดหน้า ระบบให้เปิดหน้าใหม่ก่อนรับรอง
- ข้อที่เชื่อมสูตรคำนวณแก้ถ้อยคำได้ แต่รหัส ประเภทคำตอบ กลุ่ม รหัสตัวเลือก และคะแนนยังคงเดิม
  การเปลี่ยนสูตร/โครงสร้างตัวชี้วัดต้องพัฒนาและทดสอบแยก
- รุ่น F06 ที่คัดลอกจากรุ่น 1.1 ใช้สูตรเดิมได้เมื่อโครงสร้างการคำนวณยังตรงกัน และเก็บเลขรุ่นใหม่ในผลย้อนหลัง

## การแก้ไขและลบ

แก้คำถามและตัวเลือกได้เฉพาะฉบับร่าง; คำถามที่เชื่อมตัวชี้วัดลบไม่ได้
แก้รอบได้ก่อนเตรียมพร้อม; ลบรอบได้เฉพาะร่างที่ยังไม่มีประชากรหรือประวัติงาน
แก้/ลบรายชื่อได้ก่อนตรึงประชากร; รายชื่อที่ตรึงและประวัติคำตอบ/ผลจะคงไว้
หน้าสมาชิกใช้การเพิกถอนบทบาทเพื่อเก็บประวัติ ไม่ลบบัญชีหรือคำตอบย้อนหลัง

## สิทธิ์ที่ใช้

| งาน | สิทธิ์ในขอบเขตงาน |
|---|---|
| ดู/แก้เนื้อหา | catalog.read / catalog.edit |
| ตรวจภาษา / เผยแพร่รุ่น | translation.review / catalog.publish |
| ช่วงรายงาน / รอบ | calendar.manage / round.manage |
| ประชากรและรายชื่อ | population.manage และ source.manage สำหรับแหล่งอ้างอิง |
| สร้างบัญชีและมอบบทบาท | role.manage และสิทธิ์/ระยะเวลาที่เพียงพอจะมอบบทบาทนั้น |
| มอบหมายผู้ตอบ | selfassessment.assign และ population.manage |
| คำนวณ / ส่งตรวจ / รับรองผลรวม | สิทธิ์ calculation และ result ตามหน้าปฏิบัติงานเดิม |

ชื่อบัญชี edpexadmin หรือการเป็น Django superuser ไม่แทนสิทธิ์ขอบเขตงาน
เมนูและปุ่มอาจต่างกันตามบทบาท หากไม่เห็นปุ่มมอบหมาย ให้ผู้ดูแลสิทธิ์ที่มีสิทธิ์มอบหมายนั้นมอบบทบาทผ่านหน้าสมาชิก
ผู้ตรวจชุดผลรวมยังต้องเป็นคนละคนกับผู้คำนวณตามกติกาเดิม

## การตรวจสอบรอบพัฒนานี้

ทดสอบกับ PostgreSQL จำลองที่แยกจากข้อมูลจริง:
- ชุด regression หลัก 174 กรณีผ่าน รวมคำตอบ สิทธิ์ CSRF รุ่นภาษา การคำนวณ และ snapshot เดิม
- ชุดจัดการผ่านเว็บ 20 กรณีผ่าน รวมเพิ่มบัญชี → มอบหมาย → เปิดรับ → ตอบภาษาอังกฤษ → ปิดรอบ
- ทดสอบหน้าเก่าค้าง/ข้อความเปลี่ยน/รับรองข้ามขอบเขต/แก้รุ่นเผยแพร่/รายชื่อไม่ครบ/รายชื่อตรึง/คะแนนตัวเลือกถูกดัดแปลง
- ตรวจ Django system check, JavaScript syntax และตัวเปิดอัปเดตแบบออฟไลน์

ใช้ฐานทดสอบ PGlite (PostgreSQL) ในสภาพแวดล้อมพัฒนา ยังไม่ได้รันชุดทดสอบบนฐาน Supabase ของหน่วยงาน
และยังไม่ได้ตรวจภาพหน้าจอบน Chrome/Windows จริงของผู้ใช้ในรอบนี้
