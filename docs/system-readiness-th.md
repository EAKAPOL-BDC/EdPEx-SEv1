# สถานะระบบหลังเพิ่ม F05 และการเปรียบเทียบผลจริง

เอกสารนี้แยกความสามารถที่มีโค้ดและการทดสอบแล้ว ออกจากการตรวจรับใช้งานจริง ไม่ประกาศว่าครบทุกข้อของ Blueprint 1.2

| ส่วนงาน | สถานะ |
|---|---|
| บัญชี บทบาท ขอบเขตองค์กร | มีระบบและตัวติดตั้งสิทธิ์ผู้ดูแลจากรุ่นก่อน |
| คลัง F01–F06 คำแปล รุ่น และการเผยแพร่ | มี workflow; เนื้อหาต้องผ่านการตรวจของผู้ใช้ก่อนเปิดรอบ |
| F01–F04 แบบสำรวจ | มีรับคำตอบและคำนวณจากข้อมูลจริง |
| F05 กิจกรรมพัฒนาบุคลากร | เพิ่มรับข้อมูลจริงและตรวจอ้างอิงหลักฐาน เชื่อมคำนวณ/รับรอง; ยังไม่มีอัปโหลดไฟล์หลักฐาน |
| F06 การประเมินตนเอง | มีมอบหมาย รับคำตอบและคำนวณ |
| ผลรวมและการรับรอง | มี sealed snapshots, replay validation และประวัติ |
| Dashboard ผลจริง | รายละเอียดผลและ CSV; เพิ่มเปรียบเทียบเฉพาะนิยามที่ตรงกัน |
| ข้อมูลสาธิต | 63 ตัวชี้วัด 17 กลุ่ม 198 series แยกตารางจากผลจริง |
| นำเข้าข้อมูลย้อนหลังตั้งแต่ 2565 | ยังไม่มี workflow นำเข้าพร้อมตรวจรับครบตามข้อกำหนด |
| เป้าหมาย คู่เทียบ แนวโน้มข้ามปี | ยังไม่มีระบบจัดการและจับคู่ความเทียบเคียงครบถ้วน |
| แจ้งเตือนอัตโนมัติ/ติดตามกำหนดส่ง | ยังไม่ต่อ scheduler และช่องทางส่งจริง |
| เผยแพร่ผลสู่สาธารณะ | ยังไม่มี disclosure-reviewed release workflow; ผลรับรองยังเป็นข้อมูลภายใน |
| Production และการดูแลระบบ | ต้องทดสอบ UAT บนเครื่องผู้ใช้ สำรอง/กู้คืน TLS การติดตามข้อผิดพลาด และการจัดเก็บข้อมูลก่อนใช้งานจริง |

ชุดอัปเดตนี้ไม่ได้ติดตั้งบนเครื่องผู้ใช้โดยอัตโนมัติ และไม่ได้ยืนยันว่าฐานข้อมูลจริงผ่าน migration จนกว่าผู้ใช้รันตัวติดตั้งสำเร็จ

## เพิ่มเติมรุ่นศูนย์จัดการระบบ
มีศูนย์รวมเครื่องมือผู้ดูแล การแก้ชื่อพื้นที่พร้อมประวัติ ค้น audit เฉพาะ scope ติดตามรอบและสิทธิ์ใกล้หมดอายุ และเปลี่ยนรหัสผ่านตนเองแล้ว การแจ้งเตือนในรุ่นนี้เป็นรายการบนหน้าเว็บ ไม่มี scheduler หรือการส่งอีเมล ระบบสำรอง/กู้คืนยังใช้เครื่องมือฐานข้อมูลภายนอก ไม่แสดงสถานะว่าสำรองสำเร็จโดยไม่มีหลักฐาน

## รุ่นปรับประสบการณ์ทำแบบประเมิน
ปรับตัวเลือกเป็นการ์ด แบ่งหมวด F01–F04 พร้อมความคืบหน้า และปรับ F06 ให้ใช้ตัวเลือกแบบเดียวกัน เพิ่มดูแบบประเมิน F01–F06 ตามกลุ่มจากแค็ตตาล็อก โดยเป็นโหมดตรวจนิยามทุกเงื่อนไข ไม่มีการบันทึกคำตอบ การทดสอบข้อมูล/สิทธิ์/HTML ผ่านแล้ว แต่การตรวจภาพผ่านเบราว์เซอร์รอบนี้เปิด localhost ไม่ได้ จึงยังต้องตรวจรับบนเครื่องผู้ใช้

## รุ่น Data Visualization
เพิ่มมุมมอง Endlessloop สำหรับนำเสนอวน และ FineReport สำหรับกราฟคู่ตาราง เป็นมุมมองภายใน NEXORA ไม่มีการต่อซอฟต์แวร์ FineReport ภายนอก รองรับตัวกรอง/เปรียบเทียบ/CSV จากผลรับรองหรือข้อมูลสาธิตแยกกัน คงการซ่อนข้อมูลเดิม ทดสอบข้อมูล/สิทธิ์/โครงสร้าง HTML และปุ่ม JavaScript ผ่าน 12 รายการ ยังต้องตรวจภาพบนเบราว์เซอร์ของผู้ใช้

## รุ่น Quality Upgrade

เพิ่มหน้า “คุณภาพข้อมูล” ที่ตรวจผลจริงเทียบกรอบ 63 รหัสและ replay ก่อนนับสถานะ แก้การปัดเศษและเปรียบเทียบเวลา cutoff ตรวจผลสาธิตซ้ำก่อนแสดง เพิ่ม password policy/login throttling/production configuration/health probes และเครื่องมือสำรอง PostgreSQL พร้อม checksum ปรับ design system ร่วมและหลังบ้าน รวมตัวช่วยแป้นพิมพ์/ข้อผิดพลาด/เตือนข้อมูลยังไม่บันทึก

ยังไม่ถือว่าผลจริงครบทุกกลุ่มหรือ production พร้อม: ขอบเขต C3.2 ของ 7.4-8 ต้องยืนยันจากเจ้าของข้อมูล; ยังไม่มีแผน expected coverage ครบรายช่วง/กลุ่ม/มิติ, การสำรองอัตโนมัติ, ผลซ้อม restore, MFA, monitoring/alert จริง และ UAT/ภาพบนอุปกรณ์ผู้ใช้ รายละเอียดใน `docs/nexora-quality-review-th.md` และคู่มือติดตั้งใน `docs/nexora-quality-upgrade-th.md`

## รุ่นศูนย์คู่มือการใช้งาน

เพิ่มเมนูคู่มือ ค้นหา อ่านผ่านสารบัญ และดาวน์โหลด PDF รวม 26 เล่ม 233 หน้า: ผู้ตอบ 17 กลุ่ม ผู้ปฏิบัติงาน 8 หน้าที่ และนักพัฒนา 1 เล่ม คู่มือเว็บและ PDF ใช้ต้นฉบับเดียวกัน ตรวจ checksum ก่อนดาวน์โหลด คู่มือผู้ตอบเปิดได้โดยไม่เข้าสู่ระบบ คู่มือภายในต้องเข้าสู่ระบบ และลิงก์เปิดหน้างานตรวจสิทธิ์จริงรายพื้นที่ ไม่มี migration ใหม่หรือการเปลี่ยนสิทธิ์จากการอ่านคู่มือ

ผ่านการทดสอบ 17 กรณี รวมเส้นทางคู่มือและการถดถอยของหน้าประเมิน ตรวจรูปเล่ม PDF ที่เรนเดอร์แล้วครบทุกหน้า ยังไม่ได้ยืนยันหน้าจอเว็บและการติดตั้งบนเครื่อง Windows ของผู้ใช้ รายละเอียดใน `docs/nexora-manual-center-th.md` และ `docs/nexora-manual-verification.md`

## รุ่นปรับหน้าระบบด้วยแบรนด์

เพิ่มโลโก้และมาสคอตเดิมในหน้า Admin รวมถึงส่วนต้อนรับของพื้นที่ทำงานและหลังบ้าน ปรับสัดส่วน หัวเว็บ ปุ่ม และคอลัมน์ตามหน้าจอ ใช้ส่วนโลโก้ร่วมกับหน้าสำรวจ ไม่มี migration หรือสิทธิ์ใหม่ ชุดทดสอบเดิมผ่าน 10 กรณีและตรวจหน้าที่เรนเดอร์ 13 หน้า แต่การตรวจภาพผ่านเบราว์เซอร์ยังติดข้อจำกัดเปิด localhost จึงต้องตรวจรับ Chrome/Windows หลังติดตั้ง ดู `docs/nexora-brand-interface-th.md`

## รุ่นปรับคลังแบบฟอร์ม

เพิ่มภาพรวมและกราฟสถานะจากรุ่นแบบฟอร์มที่ตรงตัวกรอง แยกการนับรุ่นออกจากการนับคำถามเพื่อป้องกันจำนวนเพิ่มซ้ำ พร้อมไอคอน F01–F06 และการ์ดที่กระชับ ไม่มี migration ใหม่ รายละเอียดและข้อจำกัดการตรวจภาพใน `docs/nexora-catalog-interface-th.md`

## รุ่นรูปแบบหน้ารายการร่วมกัน

ขยายการ์ด ไอคอน สัดส่วน และองค์ประกอบร่วมจากคลังแบบฟอร์มไปยังหน้ารายการและศูนย์งาน 12 ส่วน เพิ่มค้นหา/กรอง/กราฟสถานะรอบในหน้าเตรียมรอบ F01–F04, F05 และ F06 โดยนับข้อมูลตามสิทธิ์และตัวกรองครบทุกหน้า เพิ่มการแบ่งหน้า F05 และซ่อนทางลัดสร้างรอบจากผู้ไม่มีสิทธิ์ ไม่มี migration ใหม่ รายละเอียดการใช้งานและข้อจำกัดการตรวจภาพอยู่ใน `docs/nexora-consistent-interface-th.md`

## รุ่นจัดวางโครงหน้าร่วมกัน

จัดโลโก้และชื่อหน่วยงานเป็นองค์ประกอบเดียว เพิ่มเมนูแบบจัดหมวดยุบ–ขยายและแผงเมนูมือถือ ปรับหัวข้อ/ปุ่ม/สรุป/ตัวกรองร่วมกัน และตรึงข้อมูลผู้พัฒนากับลิขสิทธิ์โดยแยกพื้นที่ออกจากเนื้อหา ใช้ส่วนแบรนด์ร่วมกันใน Portal แบบสำรวจ และ Admin แก้การสลับภาษาที่อาจเลือก footer ภายในเอกสารคู่มือ พร้อมรักษาค่าที่ยังไม่บันทึกและตำแหน่งเลื่อน ผ่าน Django 13 และ JavaScript 9 กรณี ไม่มี migration ใหม่ ยังไม่ได้ตรวจภาพบนเบราว์เซอร์จริงเนื่องจากเปิด localhost ไม่ได้ รายละเอียดใน `docs/nexora-shell-layout-th.md`
