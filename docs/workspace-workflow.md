# NEXORA — เส้นทางใช้งานที่เชื่อมจากหน้าหลัก

เริ่มที่ `/workspace/` เลือกพื้นที่ที่ได้รับสิทธิ์ แล้วเลือก **รอบ คำเชิญ และติดตามผล**
รายการรอบและงานล่าสุดใช้กฎนำทางเดียวกัน ไม่สร้างรอบใหม่ให้อัตโนมัติ

## รอบ F01 แบบคำเชิญไม่ผูกรายชื่อ

1. เลือกรอบที่ต้องการ หากต้องการรอบใหม่ ใช้ “สร้างรอบทดสอบใหม่จากแบบนี้”
   ตรวจปี ประเภทข้อมูล บริบท จำนวนสิทธิ์ ช่วงเวลา และหลักฐานก่อนยืนยัน
2. เปิดศูนย์คำเชิญ ตรวจรายการความพร้อม แล้วเปิดรอบผ่านหน้าทบทวนและยืนยัน
3. สร้างชุดคำเชิญ บันทึกหรือพิมพ์บัตรรหัส/QR ก่อนออกจากหน้า รหัสแสดงเพียงครั้งเดียว
   แจกโดยไม่บันทึกชื่อคู่กับรหัส หนึ่งรหัสส่งได้หนึ่งครั้ง แต่ไม่ยืนยันว่าแต่ละคนได้รับเพียงรหัสเดียว
4. ผู้ตอบใช้รหัส NXA1 ที่ “ตอบด้วยคำเชิญ” ไม่ต้องสมัครสมาชิก
   ตอบทุกข้อที่แสดงยกเว้นข้อเสนอแนะ เมื่อสำเร็จเก็บรหัส/QR หลักฐานของตนไว้
5. เมื่อเก็บข้อมูลครบตามแผนให้ปิดรอบผ่านศูนย์คำเชิญ ผู้ที่กำลังตอบจะส่งเพิ่มไม่ได้
   หากเพียงต้องการหยุดชั่วคราว ให้ใช้ระงับช่องทางแทนการปิดรอบ
6. เปิด “ติดตามผลและส่งตรวจ” ตรวจความพร้อมคำนวณ ดูเวลาตัดข้อมูลและจำนวนชุดตัวชี้วัด
   แล้วบันทึกชุดผล ส่งผู้ตรวจที่มีสิทธิ์และเป็นอิสระจากผู้จัดทำ/ผู้ส่งตรวจ
7. หลังรับรอง ใช้รายงานและ CSV ตามสิทธิ์ ชุดที่ส่งกลับหรือถูกแทนที่มีคำแนะนำแยกชัดเจน

รอบที่ปิดแล้วและไม่มีคำตอบจะไม่มีข้อมูลสำหรับคำนวณ ไม่ควรเพิ่มคำตอบเพื่อให้รายงานเต็ม
การรับรองผลไม่ใช้สิทธิ์ในหลักฐาน และไม่ให้ชั่วโมงภาระงานหรือรางวัลอัตโนมัติ

## เมนูและสิทธิ์

- เมนูทั่วไปแสดงตามขอบเขตและบทบาท ผู้ตรวจไม่เห็นปุ่มออกคำเชิญหรือจัดการสมาชิกเมื่อไม่มีสิทธิ์
- เมื่ออยู่ในรอบ เมนูข้างแสดงศูนย์คำเชิญ สร้างรอบใหม่ และติดตามผลของรอบนั้นตามสิทธิ์
- ปุ่มย้อนกลับและเส้นทางด้านบนใช้รอบจากข้อมูลที่เซิร์ฟเวอร์อนุญาต ไม่อ่านรอบจากลิงก์ที่คาดเดา
- ลิงก์จัดการรอบเดิมของ F01 ที่ตั้งค่าเส้นทางใหม่แล้วพาไปศูนย์คำเชิญ/ผล
  การควบคุมสถานะผ่านหน้าเดิมถูกปิดเพื่อให้ใช้ขั้นตอนยืนยันเดียวกัน
- รหัสคำเชิญที่ไม่ใช่ NXA1 ยังใช้ช่องทางเดิม มีคำอธิบายแยกจากรหัสแบบใหม่
- รอบแบบอื่นยังใช้หน้ารอบแบบสำรวจตามการตั้งค่าของรอบนั้น ไม่ถูกเปลี่ยนรูปแบบข้อมูลย้อนหลัง

## ขอบเขตที่ต้องแยกให้ชัด

พอร์ต 8767 เป็นฐานพัฒนาแยก มีป้ายข้อมูลสมมุติและป้ายพื้นที่ทดสอบ
เส้นทางคำเชิญ NXA1 พร้อมหลักฐานที่ปรับใหม่นี้รองรับ F01 C1 ทดสอบตาม feature flags
ผลทดสอบในเครื่องไม่ได้หมายถึงการ deploy หรืออนุญาตเก็บข้อมูลจริงทุกแบบฟอร์ม
การใช้งานข้ามเครื่องต้องมีระบบบริการและ HTTPS ที่ตั้งค่าถูกต้อง ลิงก์ 127.0.0.1 เปิดได้เฉพาะเครื่องนี้
สิทธิ์ edpexadmin ยังไม่ได้เปลี่ยนตามการเลื่อนดำเนินการของผู้ใช้

ไม่มีการแก้ฐานใช้งานจริง migrate/seed/reset หรือเปิดเก็บข้อมูลจริงจากการปรับหน้าหลักนี้

## ก่อนนำไปเปิดใช้งานจริง

- ตรวจและเผยแพร่เนื้อหา/คำแปลที่ใช้จริง รวมทั้งปีและกลุ่มผู้ตอบของแต่ละแบบฟอร์ม
- เตรียมเครื่องบริการ HTTPS ที่ผู้ตอบเข้าถึงได้ และตรวจการตั้งค่าความปลอดภัยกับฐานข้อมูลจริง
- ทดสอบการกู้คืนข้อมูล การแจกคำเชิญ และสิทธิ์ผู้จัดทำ/ผู้ตรวจด้วยบัญชีแยก
- ตรวจเส้นทางออกหลักฐานของแบบฟอร์มและกลุ่มอื่นก่อนเปิดใช้ เพราะการทดสอบ NXA1 รุ่นนี้จำกัด F01 C1

ข้อเหล่านี้ยังไม่ถูกดำเนินการบนระบบใช้งานจริงจากงานปรับหน้าหลักนี้
